# Tuwa iOS UI kit
Interactive recreation of the app's core screens in the Field Notes language (evolved from the shipped v5 Pavilion — see readme.md).
- index.html — phone shell, tab switching, workout sheet
- Dashboard.jsx — Home (readiness hero, vitals, sufficiency, training load) ← 01_Dashboard
- LoadScreen.jsx — Load & progress (ACWR hero, ATL/CTL/TSB, load trend) ← 02_Workload
- WorkoutSheet.jsx — Log workout sheet ← 04_ActiveWorkout
Recovery / Workout log / Profile are intentionally left as stubs (source screenshots in assets/screens/).
