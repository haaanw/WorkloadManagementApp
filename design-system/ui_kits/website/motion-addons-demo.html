02 · LOTTIE — VECTOR MICRO-ANIMATIONS

The two animations your site ships

Lottie plays designer-authored vector animations from small JSON files — crisp at any size, ~few KB each. On tuwa.app they run only while on screen and freeze to a single frame for reduced-motion users. These are the actual files from the live site.
