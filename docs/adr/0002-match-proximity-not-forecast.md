# Match-proximity rule instead of fatigue forecasting

The TODAY verdict becomes match-aware via a single optional "next match" date and one proximity rule (tighten the verdict bound and reason when a match is near, e.g. ≤48h: cap the top set, cut back-offs), NOT via fatigue-trajectory forecasting to match day. Forecasting is the MID horizon, which is gated behind a real willingness-to-pay signal (see pressure-test 2026-06-13); the proximity rule buys the beachhead athlete's actual job ("arrive fresh for the game") for one field + one rule. The date is optional because the beachhead athlete's schedule is mixed — some weeks have a scheduled league match, some have only pickup/unscheduled play; with no scheduled match the verdict degrades gracefully to backward-only carry (unscheduled games still count — they enter as logged sessions after the fact).

## Consequences

- "Next match" becomes the first schedule-shaped plan object in the wedge. The fence is: one date, one rule, no trajectory math — anything more is MID and waits for WTP.
