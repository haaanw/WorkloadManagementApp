The five-primitive law (goes into DESIGN.md v4.1)

1 · Key — anything that commits an action: scale 0.97 + brightness on touch-down, 120ms. Release always snappy.

2 · Row — anything that navigates: background well on touch-down, NO scale (rows aren't buttons), 110ms.

3 · Detent control — anything with discrete values (toggle, stepper, segments, pickers): mechanical snap + one haptic per detent, digit-roll for value changes.

4 · Needle — anything that displays a measured value: sweeps on change (350ms), detent at band crossings, never fades or jumps.

5 · Surface — sheets/expansions: origin-aware, interruptible, 200–250ms; content staggers in 40ms steps behind the surface.

SwiftUI carriers: custom ButtonStyles (touch-down via configuration.isPressed), .sensoryFeedback, .contentTransition(.numericText), matchedGeometryEffect, scrollTransition, Animatable TickScale (already built).

3 · "Considered layout" — Home recomposed (static)

The current screens are correct but monotone: every card is full-width, every row the same height, one rhythm everywhere. The recomposition keeps the law but adds compositional contrast: an asymmetric readout, a metric grid with baseline-aligned numerals, section headers that carry a rule, and varied density between zones.

What changed, precisely: (1) score and zone form one baseline-aligned readout — big number left, zone stack right, tension across the panel instead of a lonely corner; (2) tick numerals return under the hero scale (they carry the instrument story); (3) RHR/HRV/Sleep become a 3-cell metric grid with unit-superscripts and delta lines — scannable in one fixation instead of four rows of prose; (4) section headers carry a trailing hairline rule — they structure the page instead of floating; (5) row cards get two-line rows (name + meta) so density varies between zones. Same tokens, same laws, no new colors.

References feeding this round: emilkowalski/skills (design-eng framework: frequency-based animation decisions, strong custom ease-out, touch-down feedback, interruptibility; apple-design: fluid interfaces, velocity handoff, spatial consistency, materials) · SwiftUI carriers already in the codebase or stdlib: custom ButtonStyle isPressed, .sensoryFeedback, .contentTransition(.numericText), matchedGeometryEffect, .scrollTransition, Animatable (TickScale).
