  (`WorkoutLLMImportService.swift:146`), the committed fn accepts it

  on HAN's go and never ran. Fix: `supabase functions deploy
  parse-workout` (HAN's go; includes the raised program-mode cap +

  HAN: top priority. The program-import voice door must land in an actual

## P1 — fix this release

- **U3 · Text-import sheet UX:** no keyboard dismissal (half-screen
  editing), must scroll to reach "Read my program", stray lowercase
  "Back" label under the CTA (redundant with CANCEL — delete it),
  header/spacing unpolished. Fix: scroll-to-field + keyboard toolbar
  Done (the ActiveWorkoutSheet pattern), pinned CTA, remove Back,
  spacing pass per v6.
- **U4 · Watch import incomplete + manual.** Only 3 old walk sessions
  surfaced; the recent workout missing. HAN ruling: watch workouts log
  SILENTLY in the background (no manual Add row), and the app reads the
  athlete's watch-recorded effort rating so RPE is not re-asked.
  Technical note: watchOS 11+ records Effort (1–10) as
  `HKQuantityType(.workoutEffortScore)` related to the workout — needs a
  new read type + authorization; maps to session RPE. Investigate why
  recent sessions are missed (anchor/date-window bug?) before designing.
- **U5 · Today metrics strip: sleep cell renders a different size** than
  HRV/RHR cells. Equal-width fix.
- **U6 · Profile polish set:** TrainingProfile sheet header collides
  with "Discard changes / Save profile" text over the title; name field
  has no keyboard dismissal path but Return; sports selection is
  single-select — HAN: must be MULTI-select (schema/scoring impact:
  check how sportType feeds engines before widening).

- **U11 · Multi-file program import (HAN 2026-09-09, after U1 cleared).**
  A program often spans SEVERAL photos or 2–3 PDFs; the pickers are
  single-select. Photo picker and PDF importer both go multi-select;
  extraction concatenates in user-visible order with per-file markers
  ("— page 2 —") before the one program-mode parse; the preprocessing/
  cap path (B1) must account for the larger combined text. ("Video
  files" in HAN's dictation read as PDF files — flagged, not assumed
  silently.) Owner: R1-fix lane (it owns the import sheet).

  Programs / Import AI) duplicates the on-page program door and template

  messy. Redesign the Log header + empty states around the program-led
  model.
- **U8 · Create-template DEMOTED** (HAN leaning kill; CLAUDE recommends

  same for RHR/sleep). Re-scope the Trends surface around the fatigue
  narrative (FatigueIndexEngine, ACWR history, monotony when gated).
- **U10 · Profile IA review:** why does Edit Training Profile live in a
  separate modal? Fold editing in place; review the whole page's logic.
