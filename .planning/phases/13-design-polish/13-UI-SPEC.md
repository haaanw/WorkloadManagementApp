## Typography

### Font Files

| File | Source Path | Destination |
|------|-------------|-------------|
| Alpino-Regular.otf | `Alpino_Complete/Alpino_Complete/Fonts/OTF/Alpino-Regular.otf` | `WorkloadApp/Resources/Alpino-Regular.otf` |
| Alpino-Medium.otf | `Alpino_Complete/Alpino_Complete/Fonts/OTF/Alpino-Medium.otf` | `WorkloadApp/Resources/Alpino-Medium.otf` |

### Font Registration

- Register in `Info.plist` under `UIAppFonts` array: `Alpino-Regular.otf`, `Alpino-Medium.otf`
- Remove `DMSans-Regular.ttf` and `DMSans-Medium.ttf` from `UIAppFonts` and from `WorkloadApp/Resources/`
- PostScript name must be verified from .otf metadata for `Font.custom()` calls (executor discretion)

### Type Scale (Font.Tokens)

| Token | Size | Weight | PostScript Name | Usage |
|-------|------|--------|-----------------|-------|
| heroScore | 64pt | Regular | Alpino-Regular* | Readiness score number. Accent color only. `.monospacedDigit()` at call site. |
| pageTitle | 32pt | Regular | Alpino-Regular* | Page titles |
| sectionHead | 19pt | Medium | Alpino-Medium* | Section headers |
| body | 17pt | Regular | Alpino-Regular* | Body copy, metric values |
| bodyMedium | 17pt | Medium | Alpino-Medium* | Active state labels, selected states |
| label | 15pt | Regular | Alpino-Regular* | Secondary info, factor labels |
| micro | 12pt | Regular | Alpino-Regular* | Micro labels. `.tracking(1.2)` + `.textCase(.uppercase)` at call site. |

*PostScript names are placeholders — executor MUST verify actual PostScript names from the .otf file metadata before implementation. Use `otfinfo --info Alpino-Regular.otf` or Font Book inspection.

### Size Adjustment Rule

Keep all 7 sizes (64/32/19/17/15/12) as baseline. If Alpino's x-height renders noticeably smaller than DM Sans at any size, executor may increase by 1pt maximum per token. Document any adjustments in commit message.

### Weight Mapping

| Before | After |
|--------|-------|
| DMSans-Regular (400) | Alpino-Regular |
| DMSans-Medium (500) | Alpino-Medium |

No other weights permitted. No italic. No bold.

## SharpTextFieldStyle Contract

### Specification

Create `SharpTextFieldStyle` as a `struct` conforming to `TextFieldStyle` in a new file `WorkloadApp/Components/SharpTextFieldStyle.swift`.

### Visual Properties

| Property | Value |
|----------|-------|
| Corner radius | 0pt (use `Rectangle()` shape) |
| Border width | 0.5pt |
| Border color | `ColorTokens.divider` |
| Background | `ColorTokens.surface` |
| Text color | `ColorTokens.text1` |
| Placeholder color | `ColorTokens.text3` |
| Font | `Font.Tokens.body` (17pt Regular) |
| Horizontal padding | 16pt |
| Vertical padding | 12pt (closest 8pt-grid multiple for comfortable touch target) |
| Min height | 44pt (iOS HIG touch target) |

### Focused State

| Property | Value |
|----------|-------|
| Border color | `ColorTokens.text2` (subtle lift, not accent) |
| Border width | 0.5pt (unchanged) |
| Animation | 150ms linear |

### Disabled State

| Property | Value |
|----------|-------|
| Opacity | 0.5 |
| Border color | `ColorTokens.divider` (unchanged) |

### Application Scope

Replace all `.textFieldStyle(.roundedBorder)` and `RoundedRectangle`-based text input styling in these files (23 total occurrences):

| File | Occurrences |
|------|-------------|
| `WorkloadApp/Views/WorkoutLog/ActiveWorkoutSheet.swift` | 11 |
| `WorkloadApp/Views/TemplateEditorSheet.swift` | 8 |
| `WorkloadApp/Views/PrescribeWorkoutSheet.swift` | 1 |
| `WorkloadApp/Views/Recovery/MorningCheckInSheet.swift` | 1 |
| `WorkloadApp/Views/WorkoutLog/FinishWorkoutSheet.swift` | 1 |
| `WorkloadApp/Views/WorkoutLog/ExercisePickerView.swift` | 1 |

### Usage Pattern

```swift
TextField("Placeholder", text: $value)
    .textFieldStyle(SharpTextFieldStyle())
```
