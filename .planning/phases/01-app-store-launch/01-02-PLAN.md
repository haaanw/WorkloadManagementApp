**D. Create marketing frame script**

Create `scripts/frame_screenshots.swift` -- a Swift script that uses SwiftUI's `ImageRenderer` to composite each raw screenshot with:

1. A flat rectangular device frame (no rounded corners, no shadows -- per D-04 and DESIGN.md aesthetic)
2. A headline text overlay above the device frame using DM Sans Medium font
3. Background color matching `ColorTokens.background` (use the hex value from DESIGN.md for the script)

Headlines for the 4 screens (per D-07, Claude's discretion for exact copy):
- **Dashboard:** "Know Your Readiness"
- **Recovery:** "Recovery, Decoded"
- **Workload:** "Track Training Load"
- **ActiveWorkout:** "Log Every Rep"

The script should:
- Accept input directory and output directory as arguments
- Process all PNG files found in the input directory
- Match filenames to screens (Dashboard, Recovery, Workload, ActiveWorkout) by filename content
- Render the framed image at the same pixel dimensions as the input (1290x2796 for 6.7", 1179x2556 for 6.1")
- Save output PNGs to the output directory

Design constraints for the frame:
- 0pt corner radius on everything (per DESIGN.md)
- No shadows (per DESIGN.md)
- Headline in DM Sans Medium, white text on dark background or dark text on light background (match app aesthetic)
- Clean, flat, International Style Minimalism (per DESIGN.md)
- All spacing multiples of 8pt
