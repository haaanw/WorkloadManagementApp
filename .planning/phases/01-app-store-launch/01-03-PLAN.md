**A. Verify prerequisites**

1. Confirm the user has completed Task 1 (App Store Connect record exists).
2. Check that the distribution signing identity is available:
   ```bash
   security find-identity -v -p codesigning
   ```
   Look for an "Apple Distribution" or "iPhone Distribution" certificate. If none exists, create a checkpoint asking the user to create one in Apple Developer Portal.

3. Verify the bundle ID in the project:
   ```bash
   grep "PRODUCT_BUNDLE_IDENTIFIER.*com.tonus.app;" "workload management/workload management.xcodeproj/project.pbxproj" | head -2
   ```

**B. Archive the build**

```bash
xcodebuild archive \
  -project "workload management/workload management.xcodeproj" \
  -scheme "workload management" \
  -archivePath /tmp/Tonus.xcarchive \
  -destination "generic/platform=iOS" \
  CODE_SIGN_IDENTITY="Apple Distribution" \
  -allowProvisioningUpdates
```

If the archive fails due to signing issues, create a checkpoint asking the user to configure automatic signing in Xcode or provide the correct provisioning profile.

**C. Export the archive for App Store distribution**

Create an export options plist first:

```bash
cat > /tmp/ExportOptions.plist << 'PLIST'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>method</key>
    <string>app-store-connect</string>
    <key>destination</key>
    <string>upload</string>
    <key>signingStyle</key>
    <string>automatic</string>
    <key>uploadBitcode</key>
    <false/>
    <key>uploadSymbols</key>
    <true/>
</dict>
</plist>
PLIST
```

Then export:
```bash
xcodebuild -exportArchive \
  -archivePath /tmp/Tonus.xcarchive \
  -exportOptionsPlist /tmp/ExportOptions.plist \
  -exportPath /tmp/TonusExport \
  -allowProvisioningUpdates
```

**D. Upload to App Store Connect**

The export with `method: app-store-connect` and `destination: upload` should automatically upload to TestFlight. If it does not, use Transporter or `xcrun altool`:

```bash
xcrun altool --upload-app \
  -f /tmp/TonusExport/*.ipa \
  -t ios \
  -u "<APPLE_ID>" \
  -p "<APP_SPECIFIC_PASSWORD>"
```

If altool credentials are needed, create a checkpoint for the user to provide their Apple ID and app-specific password.

**E. Verify upload**

After upload, the build will appear in App Store Connect under TestFlight within 5-30 minutes. The build must process before it can be submitted for review.
