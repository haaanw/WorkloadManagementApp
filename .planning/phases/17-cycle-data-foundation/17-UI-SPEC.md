## Spacing Scale

Declared values (must be multiples of 8pt, per DESIGN.md):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 8pt | Icon-label gaps, tight inline spacing |
| sm | 16pt | Card internal padding (horizontal), small gaps, toggle row vertical padding |
| md | 24pt | Card internal padding (vertical), standard gaps |
| lg | 32pt | Section gaps |
| xl | 48pt | Major section breaks |
| 2xl | 64pt | Page-level top/bottom breathing room |

Exceptions: None. All spacing on the 8pt grid. Toggle rows use 16pt horizontal and 16pt vertical padding.

## Typography

All text uses `Font.Tokens.*` from FontTokens.swift. No `.system()` or semantic styles.

| Role | Size | Weight | Line Height | Token |
|------|------|--------|-------------|-------|
| Body | 17pt | 400 (Regular) | 1.6 | `Font.Tokens.body` |
| Label | 15pt | 400 (Regular) | 1.5 | `Font.Tokens.label` |
| Small label | 13pt | 400 (Regular) | 1.4 | `Font.Tokens.smallLabel` |
| Micro / section header caps | 12pt | 400 (Regular) | 1.3 | `Font.Tokens.micro` + `.tracking(1.2)` + `.textCase(.uppercase)` |

## Phase 17 UI Scope

This phase has **limited UI surface**. The work is primarily backend (HealthKit service, data model, CyclePhase enum). Two UI elements are in scope:

### 1. "Cycle & Hormones" Section in ProfileView

**Location:** ProfileView, below the existing "Training Profile" section, above "Preferences" section.
**Visibility:** Section is visible ONLY when HealthKit menstrual data exists OR menstrual permissions have been granted (D-03).

**Layout:**

```
sectionHeader("CYCLE & HORMONES")            -- Font.Tokens.micro, uppercase, tracking 1.2
                                              -- text3 color, 16pt horizontal padding
Toggle row: "Hormonal Contraceptive"          -- Font.Tokens.body, text1 color
  [Toggle]                                    -- Standard SwiftUI Toggle, labelsHidden
divider()                                     -- ColorTokens.divider, 0.5pt
Toggle row: "Pregnant"                        -- Font.Tokens.body, text1 color
  [Toggle]                                    -- Standard SwiftUI Toggle, labelsHidden
divider()
Toggle row: "Lactating"                       -- Font.Tokens.body, text1 color
  [Toggle]                                    -- Standard SwiftUI Toggle, labelsHidden
sectionDivider()
```

**Interaction:**
- Toggle rows follow the exact same pattern as "Weekly Summary" toggle in Notifications section: `HStack` with label + `Spacer()` + `Toggle("", isOn:).labelsHidden()`
- Padding: 16pt horizontal, 16pt vertical per toggle row
- Toggling any value immediately saves to `Athlete` model via existing `saveAthlete()` helper
- No confirmation dialogs -- these are informational toggles, not destructive actions
- OC toggle state feeds into CycleContext downstream (Phase 18) but has no immediate UI effect beyond persisting

### 2. Soft Prompt Banner on Dashboard (One-Time)

**Location:** DashboardView, below the hero readiness card, above metrics strip.
**Trigger:** Shown once when HealthKit menstrual data is NOT available AND the user has not dismissed it before (D-02).
**Persistence:** Dismissal stored in `@AppStorage("cyclePromptDismissed")`.

**Layout:**

```
Rectangle()                                   -- ColorTokens.surface fill
  .border(ColorTokens.divider, width: 0.5)    -- Hairline border, 0pt radius
  VStack(alignment: .leading, spacing: 8) {
    HStack {
      Text("Cycle-Aware Recovery")            -- Font.Tokens.body, text1
      Spacer()
      Button { dismiss } label: {
        Image(systemName: "xmark")            -- 13pt, text2 color
      }
    }
    Text("Enable cycle tracking in Apple...")  -- Font.Tokens.label, text2
    Button("Open Settings") { openSettings }  -- Font.Tokens.label, text1, underlined
  }
  .padding(.horizontal, 16)
  .padding(.vertical, 16)
```

**Interaction:**
- "X" button dismisses permanently (sets `@AppStorage` flag)
- "Open Settings" deep-links to `UIApplication.openSettingsURLString`
- Banner never re-appears after dismissal
- If user later grants HealthKit menstrual permissions, banner also never appears

## Copywriting Contract

| Element | Copy |
|---------|------|
| Section header | CYCLE & HORMONES |
| Toggle label 1 | Hormonal Contraceptive |
| Toggle label 2 | Pregnant |
| Toggle label 3 | Lactating |
| Soft prompt heading | Cycle-Aware Recovery |
| Soft prompt body | Track your menstrual cycle in Apple Health to get cycle-aware recovery insights. Faros reads existing data from apps like Clue, Flo, or Apple Cycle Tracking -- no manual re-entry needed. |
| Soft prompt CTA | Open Settings |
| Empty state (no cycle data, prompt dismissed) | No UI -- section simply does not appear. Existing app behavior unchanged. |
| Error state (HealthKit fetch fails) | No visible error -- cycle features silently degrade. Recovery scoring falls back to existing 7-day baseline. Log error with `"Cycle data fetch error: \(error)"` pattern. |
| Destructive actions | None in this phase. Toggles are non-destructive state changes. |

## Interaction States

### ProfileView "Cycle & Hormones" Section

| State | Behavior |
|-------|----------|
| HealthKit menstrual permission NOT granted AND no menstrual data | Section hidden entirely |
| HealthKit menstrual data exists (from Clue/Flo/Apple) | Section visible with toggles |
| User toggles "Hormonal Contraceptive" ON | Persists to Athlete.isOnHormonalContraceptive. No confirmation. |
| User toggles "Pregnant" ON | Persists to Athlete.isPregnant. No confirmation. |
| User toggles "Lactating" ON | Persists to Athlete.isLactating. No confirmation. |

### Dashboard Soft Prompt

| State | Behavior |
|-------|----------|
| No menstrual data AND prompt not dismissed | Banner visible below hero card |
| User taps "X" | Banner dismissed permanently, @AppStorage flag set |
| User taps "Open Settings" | Opens iOS Settings app |
| Menstrual data becomes available | Banner hidden (data exists, no prompt needed) |
| Prompt already dismissed | Banner never shown again |

## Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Toggle labels | Each toggle has a descriptive label as the HStack Text -- VoiceOver reads "Hormonal Contraceptive, toggle button" |
| Banner dismiss | "X" button needs `.accessibilityLabel("Dismiss cycle tracking prompt")` |
| Color independence | No information is conveyed through color alone in this phase. All states use text labels. |
| Dynamic Type | Font.Tokens uses `Font.custom()` which respects Dynamic Type scaling |
