# Plan 17-04: Gap Closure — HealthKit Menstrual Authorization

<objective>
Add the 6 menstrual HKCategoryType entries to HealthKitService.readTypes so that requestAuthorization() asks for menstrual data permission. Without these, CycleTrackingService silently gets empty results from HealthKit for all users.
</objective>

<source>
Gap 1 from 17-VERIFICATION.md: "HealthKitService.readTypes (lines 38-56) contains only the original 8 types — none of the 6 menstrual HKCategoryType entries are present."
</source>

<tasks>

<task id="1" name="Add menstrual HKCategoryTypes to readTypes" type="execute">

<read_first>
- WorkloadApp/Services/HealthKitService.swift (current readTypes set at lines 38-56)
- WorkloadApp/Services/CycleTrackingService.swift (verify which types it queries)
</read_first>

<action>
In HealthKitService.swift, add these 6 lines inside the `readTypes` computed property's initial Set literal (after the existing `HKCategoryType(.sleepAnalysis)` line, before the closing `]`):

```swift
HKCategoryType(.menstrualFlow),
HKCategoryType(.contraceptive),
HKCategoryType(.pregnancy),
HKCategoryType(.lactation),
HKCategoryType(.irregularMenstrualCycles),
HKCategoryType(.ovulationTestResult),
```

This ensures requestAuthorization() will include menstrual data in the permission dialog, allowing CycleTrackingService queries to return real data.
</action>
