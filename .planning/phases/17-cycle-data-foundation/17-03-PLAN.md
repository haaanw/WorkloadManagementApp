Add "Cycle & Hormones" section to ProfileView, inserted between the TRAINING PROFILE `sectionDivider()` (around line 82) and the PREFERENCES `sectionHeader("PREFERENCES")` (around line 85).

**Section visibility condition:** The section should be visible only when menstrual data exists. For Phase 17, use a simple heuristic: show the section when the athlete has any `menstrualCycleSnapshots` OR when any of the 3 fields are already set (non-nil). This avoids the HealthKit authorization status ambiguity (Pitfall 1 -- cannot distinguish "denied" from "not determined").

Add a `@Query` for MenstrualCycleSnapshot at the top of ProfileView alongside the existing queries:
```swift
@Query private var cycleSnapshots: [MenstrualCycleSnapshot]
```

Add a computed property for section visibility:
```swift
private var showCycleSection: Bool {
    !cycleSnapshots.isEmpty ||
    athlete?.isOnHormonalContraceptive != nil ||
    athlete?.isPregnant != nil ||
    athlete?.isLactating != nil
}
```

Insert the following section between TRAINING PROFILE sectionDivider() and PREFERENCES sectionHeader():

```swift
// Cycle & Hormones (D-03)
if showCycleSection {
    sectionHeader("CYCLE & HORMONES")

    // Hormonal Contraceptive toggle
    HStack {
        Text("Hormonal Contraceptive")
            .font(.Tokens.body)
            .foregroundStyle(ColorTokens.text1)
        Spacer()
        Toggle("", isOn: Binding(
            get: { athlete.isOnHormonalContraceptive ?? false },
            set: { newValue in
                athlete.isOnHormonalContraceptive = newValue
                saveAthlete(athlete)
            }
        ))
        .labelsHidden()
    }
    .padding(.horizontal, 16)
    .padding(.vertical, 16)

    divider()

    // Pregnant toggle
    HStack {
        Text("Pregnant")
            .font(.Tokens.body)
            .foregroundStyle(ColorTokens.text1)
        Spacer()
        Toggle("", isOn: Binding(
            get: { athlete.isPregnant ?? false },
            set: { newValue in
                athlete.isPregnant = newValue
                saveAthlete(athlete)
            }
        ))
        .labelsHidden()
    }
    .padding(.horizontal, 16)
    .padding(.vertical, 16)

    divider()

    // Lactating toggle
    HStack {
        Text("Lactating")
            .font(.Tokens.body)
            .foregroundStyle(ColorTokens.text1)
        Spacer()
        Toggle("", isOn: Binding(
            get: { athlete.isLactating ?? false },
            set: { newValue in
                athlete.isLactating = newValue
                saveAthlete(athlete)
            }
        ))
        .labelsHidden()
    }
    .padding(.horizontal, 16)
    .padding(.vertical, 16)

    sectionDivider()
}
```

The entire block is inside `if showCycleSection { ... }` so it is invisible when no cycle data exists and no flags are set. Each toggle uses the existing `saveAthlete(athlete)` helper which calls `pushAthlete` to sync to Supabase.

Use 16pt vertical padding per toggle row (matching UI-SPEC specification), not 12pt.

```swift
if showCyclePrompt {
    VStack(alignment: .leading, spacing: 8) {
        HStack {
            Text("Cycle-Aware Recovery")
                .font(.Tokens.body)
                .foregroundStyle(ColorTokens.text1)
            Spacer()
            Button {
                cyclePromptDismissed = true
            } label: {
                Image(systemName: "xmark")
                    .font(.system(size: 13))
                    .foregroundStyle(ColorTokens.text2)
            }
            .accessibilityLabel("Dismiss cycle tracking prompt")
        }
        Text("Track your menstrual cycle in Apple Health to get cycle-aware recovery insights. Faros reads existing data from apps like Clue, Flo, or Apple Cycle Tracking \u{2014} no manual re-entry needed.")
            .font(.Tokens.label)
            .foregroundStyle(ColorTokens.text2)
        Button {
            if let url = URL(string: UIApplication.openSettingsURLString) {
                UIApplication.shared.open(url)
            }
        } label: {
            Text("Open Settings")
                .font(.Tokens.label)
                .foregroundStyle(ColorTokens.text1)
                .underline()
        }
    }
    .padding(.horizontal, 16)
    .padding(.vertical, 16)
    .background(ColorTokens.surface)
    .overlay(
        Rectangle()
            .stroke(ColorTokens.divider, lineWidth: 0.5)
    )
    .padding(.horizontal, 16)
    .padding(.top, 8)
}
```

Key design rules from UI-SPEC:
- 0pt border radius (use `Rectangle()`, never `RoundedRectangle`)
- No shadows
- Font.Tokens only (no .system() except for the xmark icon size)
- ColorTokens only (no hardcoded hex)
- "X" dismiss is permanent via `@AppStorage`
- "Open Settings" deep-links to iOS Settings
- Banner never re-appears once dismissed OR once cycle data exists
