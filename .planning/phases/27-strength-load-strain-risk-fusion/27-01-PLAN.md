  <name>Task 1: est-1RM, relative-intensity buckets, RIR bridge, hard-set rule (pure primitives)</name>
  <files>WorkloadApp/Services/StrengthLoadEngine.swift, WorkloadApp/WorkloadAppTests/StrengthLoadEngineTests.swift</files>
  <behavior>
    - estimatedOneRM(weight, reps): Epley `weight * (1 + reps/30)`; reps==1 returns weight; weight<=0 returns nil.
    - estRIR(rpe): `max(0, 10 - rpe)` when rpe present; nil when rpe nil.
    - relativeIntensity(weight, e1RMReference): `weight / ref` when ref>0; nil otherwise.
    - intensityBucket(relIntensity): light(<0.65), moderate(0.65..<0.80), heavy(0.80..<0.90), maximal(>=0.90); named constants.
    - isHardSet(set, e1RMReference): false if isWarmup; true if relIntensity >= hardSetIntensityThreshold OR estRIR <= hardSetRIRThreshold; sets with neither weight>0 nor rpe -> classified `unscored` (NOT hard, NOT easy).
    - All thresholds are named constants in an enum Constants.
  </behavior>
  <action>
Create `WorkloadApp/Services/StrengthLoadEngine.swift` as a pure `struct` with `static`
methods, Foundation-only, deterministic — mirror the named-constant style of
`FatigueIndexEngine` (an `enum Constants` / `enum Weights` block, doc comments).
Implement est-1RM (Epley, per D-27-04), `estRIR` (RPE→RIR), `relativeIntensity`,
`intensityBucket` (define a nested `enum IntensityBucket: light/moderate/heavy/maximal`),

points, and per-bucket strain weights. Do NOT compute or expose raw tonnage anywhere.
