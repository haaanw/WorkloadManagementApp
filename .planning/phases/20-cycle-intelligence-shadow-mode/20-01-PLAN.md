<objective>
Build the silent shadow-mode foundation: a local-only `CyclePredictionLog` SwiftData model and a pure `ShadowPredictor` engine that, for each of the four tracked outcomes, produces a baseline prediction (no cycle phase) and a cycle-aware prediction (baseline + a fixed literature-derived phase offset), plus an absolute-error helper. No pipeline wiring, no modifiers, no UI — those are Plans 02 and 03.

Purpose: This is the measurement substrate for the entire phase. Before any cycle modifier is allowed to affect a real user (a future phase), we must be able to ask, per athlete over time, "does adding cycle phase as a feature reduce prediction error for next-day recovery / wellness / completion / pain?" This plan defines the data shape that answer is computed from and the deterministic predictor that generates the two competing predictions — keeping the engine pure and the storage local-only and unsynced (D-13 / Phase 17 D-12 privacy).

Output: `CyclePredictionLog.swift` (@Model, registered in the schema), `ShadowPredictor.swift` (pure struct), schema + PreviewData registration, and unit tests proving the unknown-phase equivalence, the offset direction, and the error metric.
</objective>
