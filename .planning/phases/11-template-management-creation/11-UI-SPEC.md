## Spacing Scale

Declared values (8pt grid, per DESIGN.md):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 8pt | Icon-label gaps, inline padding, tight spacing |
| sm | 16pt | Card internal padding (horizontal), small gaps, horizontal margins |
| md | 24pt | Card internal padding (vertical), standard gaps |
| lg | 32pt | Section gaps |
| xl | 48pt | Major section breaks |
| 2xl | 64pt | Page-level top/bottom breathing room |

Exceptions:
- 4pt: used for tight vertical gaps within set rows (existing pattern in TargetSetRow: 6pt padding is a pre-existing deviation -- new code must use 8pt)
- 12pt: pre-existing in some list row vertical padding -- maintain for visual density in session rows but do not introduce new 12pt values
- 40pt: existing filter bar height -- maintain

Source: DESIGN.md spacing table

## Typography

Phase 11 uses 4 sizes from the project type scale. See DESIGN.md for the full project type scale (Hero score 56pt, Page title 28pt, etc.) which Phase 11 does not use.

| Role | Size | Weight | Line Height | Font Token |
|------|------|--------|-------------|------------|
| Section head | 19pt | 500 (Medium) | 1.3 | `.Tokens.sectionHead` |
| Body / Body Medium | 17pt | 400 (Regular) / 500 (Medium) | 1.5 | `.Tokens.body` / `.Tokens.bodyMedium` |
| Label | 15pt | 400 (Regular) | 1.4 | `.Tokens.label` |
| Micro | 12pt | 400 (Regular) | 1.3 | `.Tokens.micro` |

**19pt rationale:** DESIGN.md specifies 17pt for section head, but the shipped codebase token in `FontTokens.swift` defines `.Tokens.sectionHead` as 19pt. All existing views reference this token. Phase 11 follows the implemented token value to maintain visual consistency with the rest of the app. If DESIGN.md is updated in a future pass, the token will propagate the change automatically.

Rules:
- All numeric displays use `.monospacedDigit()`
- Micro labels use `.tracking(1.2)` and `.textCase(.uppercase)`
- Never use `.system()` or semantic styles (`.headline`, `.body`)
- All text via `Font.custom("DMSans-Regular/Medium", size:)` or the `.Tokens.*` extension

Source: DESIGN.md type scale, FontTokens.swift

## Component Inventory

### 1. Template Carousel (new)

**Location:** Top of `WorkoutLogView`, above session history, below filter bar.

**Layout:**
- Horizontal `ScrollView(.horizontal, showsIndicators: false)` with snap behavior
- Centered card is 280pt wide, 160pt tall
- Adjacent cards scale to 0.85x via `GeometryReader` + `scaleEffect`
- Adjacent cards have 0.6 opacity
- Card spacing: 16pt between card edges
- Carousel horizontal inset: 16pt from screen edges (matching existing horizontal margins)
- Section label above carousel: "MY TEMPLATES" in `.Tokens.micro` + `.tracking(1.2)` + `.textCase(.uppercase)`, `ColorTokens.text3`, 16pt horizontal padding, 8pt bottom padding

**Card design (TemplateCarouselCard):**
- Background: `ColorTokens.surface`
- Border: `Rectangle()` with 0.5pt `ColorTokens.divider` border (per DESIGN.md: 0pt radius, no shadows)
- Internal padding: 16pt horizontal, 16pt vertical
- Top-left: Template name in `.Tokens.body` / `ColorTokens.text1`, truncated to 2 lines
- Below name: Sport type + session type in `.Tokens.label` / `ColorTokens.text2`
- Below type: Exercise count summary "N exercises, N sets" in `.Tokens.label` / `ColorTokens.text2`
- Bottom-left: Scheduled days rendered as weekday initials (M T W T F S S) in `.Tokens.micro`, scheduled days in `ColorTokens.text1`, unscheduled in `ColorTokens.text3`
- Top-right: Star icon (SF Symbol `star.fill` when favorited, `star` when not) in `ColorTokens.zoneCaution` when favorited, `ColorTokens.text3` when not, 15pt
- Bottom-right: "Last used [relative date]" in `.Tokens.micro` / `ColorTokens.text3` if `lastUsedAt` exists; omit if nil

**Centering logic:**
1. Find template where `scheduledDays` contains today's ISO weekday (1=Mon...7=Sun)
2. If multiple match, pick the one with most recent `lastUsedAt`
3. If none match, center on template with most recent `lastUsedAt`
4. If no templates have `lastUsedAt`, center on first template

**Interactions:**
- **Tap centered card:** Open template preview sheet (see Component 2)
- **Tap non-centered card:** Scroll to center that card (with 250ms easeOut animation)
- **Long-press any card:** iOS `.contextMenu` with: Edit Template, Duplicate Template, Favorite/Unfavorite, Archive Template, Delete Template
- **Swipe left on centered card:** Reveal archive and delete action buttons (custom implementation since not a List row)
- Carousel uses `.scrollTargetBehavior(.viewAligned)` for snap-to-center

**"New Template" card:**
- Appears as the last card in the carousel
- Same dimensions as template cards
- Background: `ColorTokens.background` (not surface -- visually distinct)
- Border: 0.5pt dashed `ColorTokens.divider`
- Center content: SF Symbol `plus` at 24pt in `ColorTokens.text2`, below it "Create Template" in `.Tokens.label` / `ColorTokens.text2`
- Tap: Open `TemplateEditorSheet` in create mode

### 2. Template Preview Sheet (new, discretion: D-04)

**Rationale:** Preview-then-start over direct workout launch because (a) Phase 11 does not include template-driven workout launching (Phase 12), so tap must do something useful now, and (b) preview lets users see full exercise breakdown before editing.

**Presentation:** `.sheet` half-height detent (`.presentationDetents([.medium, .large])`)

**Layout:**
- Header: Template name in `.Tokens.sectionHead` / `ColorTokens.text1`
- Subheader: Sport type + session type in `.Tokens.label` / `ColorTokens.text2`
- Scheduled days row: Weekday pills (same as carousel card, but larger -- 15pt)
- Divider: 0.5pt `ColorTokens.divider`
- Exercise list: For each group, group name in `.Tokens.micro` / `ColorTokens.text3` (uppercase + tracking), then exercises listed as rows: exercise name in `.Tokens.body` / `ColorTokens.text1`, set summary "N sets x N reps @ Nkg" in `.Tokens.label` / `ColorTokens.text2`
- Bottom toolbar: "Edit Template" button (`.Tokens.body` / `ColorTokens.text1`)
- Notes (if present): Below exercises, `.Tokens.label` / `ColorTokens.text2`

**Note:** "Start Workout" button will be added in Phase 12 when template-driven workouts are implemented.

### 3. Save-as-Template Integration (modification to ActiveWorkoutSheet)

**Decision D-05:** Toggle in finish confirmation dialog.
**Decision D-06 (discretion):** Quick save with auto-naming. Opening the full editor after a workout would be friction-heavy. Instead, save immediately with a toast, and let users edit the template later from the carousel.

**Implementation:**
- Replace the current `.alert("Finish Workout")` with a custom sheet or expanded alert
- Add a `Toggle` row below the RPE display: "Save as Template" with `.Tokens.body` label, `ColorTokens.text1`
- Toggle is OFF by default
- When toggled ON, show an editable `TextField` for template name, pre-filled with session name or sport type display name
- When user taps "Finish Workout", if toggle is ON: create `WorkoutTemplate` with `isAthleteOwned=true`, auto-generate groups (all exercises in one "Main" group), actuals become targets
- After save, show a brief confirmation: "Template saved" (toast-style banner, 2s auto-dismiss)
- If template save fails, show error toast: "Couldn't save template. Try again." (toast-style banner, 3s auto-dismiss)
- Template name field: `.Tokens.body` / `ColorTokens.text1`, placeholder in `ColorTokens.text3`

**Finish dialog revised layout:**
- Title: "Finish Workout" in `.Tokens.sectionHead` / `ColorTokens.text1`
- RPE display: "RPE: N" with stepper or slider (preserve existing pattern)
- Divider: 0.5pt
- Save-as-template toggle row
- Template name field (visible only when toggle is ON)
- Action buttons: "Finish Workout" (primary, `ColorTokens.text1`), "Keep Editing" (secondary, `ColorTokens.text2`)

### 4. TemplateEditorSheet Modifications (existing component)

**New fields to add (D-09, D-10):**

**Scheduled Days Picker:**
- Location: Below the Notes field, before exercise groups
- Label: "SCHEDULE" in `.Tokens.micro` / `ColorTokens.text3` with tracking + uppercase
- Seven day buttons in a horizontal row: M T W T F S S
- Each button: 40pt x 40pt, `Rectangle()` shape (0pt radius)
- Unselected: `ColorTokens.background` fill, `ColorTokens.text2` text, 0.5pt `ColorTokens.divider` border
- Selected: `ColorTokens.surface` fill, `ColorTokens.text1` text, 0.5pt `ColorTokens.text1` border
- Font: `.Tokens.label` (15pt)
- Spacing between buttons: 8pt
- Row padding: 16pt horizontal, 16pt vertical

**Favorite Toggle:**
- Location: Below scheduled days picker
- Standard SwiftUI `Toggle` with label "Favorite" in `.Tokens.body` / `ColorTokens.text1`
- Toggle tint: `ColorTokens.zoneCaution` (matches star color)
- 16pt horizontal padding

**Athlete-mode adjustments:**
- When `isAthleteOwned=true`, the editor does not show `coachId` field (it is set automatically)
- "Save" button label in toolbar: `ColorTokens.text1` when valid, `ColorTokens.text3` when disabled (preserve existing pattern)

### 5. Context Menu Actions (D-13)

Long-press on any carousel card shows:

| Action | SF Symbol | Label | Color |
|--------|-----------|-------|-------|
| Edit | `pencil` | "Edit Template" | `ColorTokens.text1` |
| Duplicate | `doc.on.doc` | "Duplicate Template" | `ColorTokens.text1` |
| Favorite | `star.fill` / `star` | "Favorite" / "Unfavorite" | `ColorTokens.text1` |
| Archive | `archivebox` | "Archive Template" | `ColorTokens.text1` |
| Delete | `trash` | "Delete Template" | `ColorTokens.zoneDanger` |

**Delete confirmation (D-14):**
- `.alert` with title: "Delete Template?" in system alert style
- Message: "This will permanently remove '[template name]'. This cannot be undone."
- Destructive button: "Delete" (system destructive role)
- Cancel button: "Cancel" (cancel role -- system alert convention, not a custom CTA)

### 6. Swipe Actions (D-12)

**Swipe left on centered carousel card reveals:**
- Archive button: `archivebox` icon + "Archive" text label, `ColorTokens.text1` on `ColorTokens.surface` background. VoiceOver accessibility label: "Archive template"
- Delete button: `trash` icon + "Delete" text label, `ColorTokens.zoneDanger` on `ColorTokens.surface` background. VoiceOver accessibility label: "Delete template"
- Each button: 72pt wide, icon above text, icon at 17pt, text in `.Tokens.micro` (12pt)
- Swipe uses custom drag gesture (not `.swipeActions` -- carousel cards are not List rows)
- 250ms easeOut animation for reveal/hide
