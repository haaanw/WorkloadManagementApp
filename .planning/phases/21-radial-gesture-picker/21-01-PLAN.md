    - Collapsed state: a full-width 0pt-corner Rectangle tile showing the selected option's `radialIcon` + `displayName`, hairline divider border, matching segmented-control visual weight; a long-press (>=0.3s) opens the ring
    - Open: ring fades/scales in over 250ms easeOut; one UIImpactFeedbackGenerator(.medium) fires; a dimming scrim (ColorTokens.background.opacity) covers the screen
    - Layout: options at angle = -90deg + i*(360/N), placed on a radius; works for any N>=2 (test with 5 and 7)
    - Drag: finger vector from center -> if magnitude < deadZoneRadius (e.g. 64pt) or > cancelRadius (e.g. diameter*0.375 outer), highlighted = nil; else highlighted = option at the nearest sector. Each time `highlighted` changes to a non-nil option, fire a light/selection haptic
    - Highlighted option renders with text1 + hairline text1 border (150ms linear); others text2
    - Release on a non-nil highlighted option: set `selection.wrappedValue`, fire .medium haptic, animate ring closed (250ms easeIn)
    - Release with highlighted == nil (center dead zone or outside cancel radius): animate ring closed, binding UNCHANGED, no commit haptic
    - Accent color is used NOWHERE in the component
    - Accessibility (D-14): if `@Environment(\.accessibilityVoiceOverEnabled)` OR `@Environment(\.accessibilityReduceMotion)` is true, the long-press overlay is replaced by an accessible tap target (Menu or 0pt-corner button list) presenting all options by `displayName`; Reduce Motion sets animation duration to 0. Each ring option exposes an `.accessibilityLabel(displayName)` + `.accessibilityAddTraits(.isButton)`
    - Pure geometry is factored so it is unit-testable without a running UI: a helper computing (a) per-index angle, (b) per-index offset point for a given radius, (c) classification of a center-relative point into highlighted-index? / nil (dead zone / cancel)
  </behavior>

    Collapsed tile: mirror MetricTile/TimeRangeSegmentedControl idiom — `Rectangle().fill(ColorTokens.surface)` + `.overlay(Rectangle().stroke(ColorTokens.divider, lineWidth: 0.5))`, `Image(systemName: selection.radialIcon)` + `Text(selection.displayName)` in `Font.Tokens.body`/`text1`, 16pt padding.     Geometry helper: a private `struct RadialRingGeometry { let count: Int; let diameter: CGFloat; let deadZoneRadius: CGFloat; func angle(forIndex:) -> CGFloat; func point(forIndex:radius:) -> CGSize; func highlightIndex(for point: CGPoint) -> Int? }` (returns nil for dead zone / beyond cancel radius). Keep it free of SwiftUI view types so it is testable.
