<objective>
Implement B.1 — Quick mode for returning recovery check-ins by PRE-FILLING the existing
MorningCheckInSheet rather than building a separate quick screen. When a prior WellnessCheckIn
exists, seed the sheet's sliders (sleepQuality, soreness, energy, stress) and behavior tags from
the most recent prior check-in (or today's if it already exists) so returning users edit only the
deltas, then save. Show a subtle "prefilled from last check-in" hint. First-ever check-in keeps
defaults (3) with no hint. Notes are not carried.

Purpose: Cut the ~daily friction of re-answering 5 sliders + tags from scratch for serious
amateur athletes with no coach — the returning case is the common case.
Output: A read-only repository fetch + pre-fill logic + localized hint string. NO engine change,
NO schema change, full 5-section form unchanged.
</objective>
