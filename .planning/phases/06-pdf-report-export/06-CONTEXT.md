# Phase 6: PDF Report Export - Context

**Gathered:** 2026-04-25
**Status:** Ready for planning

<domain>
## Phase Boundary

Athletes and coaches can generate professional PDF reports of training data for review and sharing. Covers athlete single-report generation, coach multi-athlete roster summary, subscription gating (Pro/Coach = PDF, free = CSV only), and sharing via system share sheet.

</domain>

<decisions>
## Implementation Decisions

### Report Content & Sections
- **D-01:** Default report period is last 4 weeks (matches ACWR window). User can change before generating.
- **D-02:** Athlete PDF includes four sections: (1) Recovery overview with score trend line + current score + sleep/HRV composite summaries, (2) Workload trends with ATL/CTL/ACWR chart + current zone, (3) Session log table (date, sport, duration, RPE, load), (4) Personal records achieved in period.
- **D-03:** Report opens with a key metrics header — snapshot showing current recovery score, ACWR zone, streak count, sessions in period, PRs hit. Quick glance before detail sections.
- **D-04:** No raw HealthKit values in PDF — composite scores only (recovery score, HRV composite, sleep composite). Consistent with existing CSV export and Apple guidelines.

### PDF Visual Design
- **D-05:** Clean data report style following DESIGN.md aesthetic — DM Sans font, 0pt corners, no shadows, hairline borders. Tables + simple drawn charts via UIGraphicsPDFRenderer.
- **D-06:** US Letter page size (8.5x11").
- **D-07:** Branded header on each page: "Tonus" wordmark top-left, athlete name + date range top-right. Footer with page number and "Generated by Tonus" tagline.

### Coach Multi-Athlete Report
- **D-08:** Coach report is a roster summary table — one table with each athlete as a row showing recovery score, ACWR zone, sessions count, streak, flag if overreaching. Not individual detail pages.
- **D-09:** Coach can multi-select which athletes to include before generating (athlete picker UI).

### Export Trigger & Date Range
- **D-10:** Athlete PDF export triggered from Workload tab — add PDF option alongside existing CSV export in WorkloadView's confirmationDialog.
- **D-11:** Date range selection uses preset chips: "Last 4 weeks" (default), "Last 8 weeks", "Last 12 weeks". Matches existing time range picker pattern.
- **D-12:** Coach report export triggered from Coach Roster screen — "Export Report" button on CoachRosterView, opens athlete picker then generates.
- **D-13:** Sharing via existing ShareSheet (UIActivityViewController wrapper already in codebase).

### Subscription Gating
- **D-14:** PDF export gated behind isPro (Athlete Pro or Coach entitlement). Free users retain CSV export only. Uses existing SubscriptionService gating pattern.

### Claude's Discretion
- Chart rendering approach within UIGraphicsPDFRenderer — Claude decides how to draw trend lines and bar charts using Core Graphics primitives
- Section page breaks — Claude decides when sections flow onto next page vs force page break
- Exact table column widths and cell padding for session log and roster summary

</decisions>
