Horizontal HStack with 8pt spacing. Each chip is a `Button` with:

**Generate button:**
- Full-width `Rectangle()` with `ColorTokens.text1` fill
- Text "Generate Report" in `ColorTokens.background` color, DM Sans Medium 15pt
- 16pt vertical padding
- When `isGenerating`: text changes to "Generating...", show `ProgressView()`, button disabled
- On tap: call `generateReport()`

**generateReport() method:**
1. Set `isGenerating = true`
2. Fetch data from repositories using `modelContext`:
   - `let workoutRepo = WorkoutRepository(modelContext: modelContext)`
   - `let sessions = try workoutRepo.fetchSessions(last: selectedRange.days)`
   - `let workloadRepo = WorkloadRepository(modelContext: modelContext)`
   - `let workloadSnapshots = try workloadRepo.fetchSnapshots(last: selectedRange.days)`
   - `let recoveryRepo = RecoveryRepository(modelContext: modelContext)`
   - `let recoverySnapshots = try recoveryRepo.fetchRecoveryHistory(days: selectedRange.days)`
   - PersonalRecords: use `modelContext.fetch(FetchDescriptor<PersonalRecord>(...))` with date predicate for `achievedAt` in range
   - `let streakCount = StreakEngine.computeStreak(sessions: sessions)`
3. Call `PDFReportEngine.generateAthleteReport(athlete:sessions:workloadSnapshots:recoverySnapshots:personalRecords:streakCount:dateRange:)`
4. Write returned `Data` to temp file: `FileManager.default.temporaryDirectory.appendingPathComponent("tonus_report_\(dateString).pdf")`
5. Set `exportFileURL = tempURL`, `showShareSheet = true`
6. On error: set `errorMessage = "Report generation failed. Please try again."`
7. Set `isGenerating = false`

**subtitleText computed property:**
Return `"\(athlete.displayName) - \(athlete.sportType.displayName)"` where athlete = `athletes.first`, or empty string if nil.
