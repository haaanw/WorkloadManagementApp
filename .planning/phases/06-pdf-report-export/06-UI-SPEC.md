# Phase 6 — UI Design Contract

> Visual and interaction contract for PDF report export. Generated by gsd-ui-researcher.
> This phase has TWO visual surfaces: (1) in-app UI for triggering/configuring export, (2) the PDF document itself rendered via UIGraphicsPDFRenderer.

---

| Property | Value |

## Spacing Scale

All values are multiples of 8pt, matching DESIGN.md.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 8pt | Icon-label gaps, inline chip padding, table cell internal |
| sm | 16pt | Card internal horizontal padding, chip horizontal padding |
| md | 24pt | Card internal vertical padding, section gaps within PDF |
| lg | 32pt | Section gaps in-app, PDF section breaks |
| xl | 48pt | Major section breaks in PDF |
| 2xl | 64pt | PDF page top/bottom margins |

Exceptions: PDF page margins use 48pt left/right and 64pt top/bottom for US Letter printability (source: D-06).

## Component Inventory

### In-App Components (SwiftUI)

#### 1. Export Format Confirmation Dialog (extends existing)

Location: WorkloadView.swift existing `confirmationDialog`

Add one new button: "PDF Report (Pro)" alongside existing CSV options. If user is not Pro, tapping shows UpgradeSheet instead.

```
confirmationDialog options:
  - "Session Summary (CSV)"      [existing]
  - "Detailed Sets (CSV)"        [existing]
  - "PDF Report (Pro)"           [NEW — gated]
  - "Cancel"                     [existing]
```

#### 2. Date Range Chip Selector

Appears after user selects "PDF Report" and before generation begins. Presented as a sheet or inline section.

- Layout: Horizontal row of 3 chips, left-aligned, 8pt gap between chips
- Chip style: `Rectangle()` fill `ColorTokens.surface`, 0.5pt `ColorTokens.divider` border, 0pt corner radius
- Selected chip: `ColorTokens.text1` border (1pt), `ColorTokens.text1` text
- Unselected chip: `ColorTokens.divider` border (0.5pt), `ColorTokens.text2` text
- Chip labels: "Last 4 weeks" (default selected), "Last 8 weeks", "Last 12 weeks"
- Chip internal padding: 8pt vertical, 16pt horizontal
- Font: DM Sans Regular 13pt
- Touch target: minimum 44pt height

Source: D-11

#### 3. PDF Generation Sheet

A minimal sheet that shows date range selection + "Generate Report" CTA button.

- Title: "Export PDF Report" — DM Sans Medium 17pt, ColorTokens.text1
- Subtitle: athlete name + sport type — DM Sans Regular 13pt, ColorTokens.text2
- Date range chips (component 2 above)
- CTA button: full-width Rectangle(), ColorTokens.text1 fill, ColorTokens.background text, DM Sans Medium 15pt, 16pt vertical padding
- Loading state: Replace button label with "Generating..." + ProgressView, button disabled
- Sheet padding: 24pt all sides
- Sheet background: ColorTokens.background

#### 4. Coach Athlete Picker Sheet

Location: Triggered from CoachRosterView "Export Report" button

- Title: "Select Athletes" — DM Sans Medium 17pt
- Subtitle: "Choose athletes to include in the roster report" — DM Sans Regular 13pt, ColorTokens.text2
- List of athlete rows, each with:
  - Checkmark toggle (SF Symbol `checkmark.circle.fill` / `circle`) — 24pt, leading
  - Athlete name — DM Sans Regular 15pt, ColorTokens.text1
  - Current zone badge — text label with colored 0.5pt border, DM Sans Regular 11pt
  - Row height: 48pt minimum
  - Row separator: 0.5pt ColorTokens.divider hairline
- "Select All" / "Deselect All" toggle in toolbar — DM Sans Regular 13pt
- Date range chips (same component 2)
- CTA button: "Generate Roster Report" — same style as component 3 CTA
- Bottom safe area: 16pt padding below CTA

Source: D-08, D-09, D-12

#### 5. Coach Export Button

Location: CoachRosterView toolbar

- SF Symbol: `doc.text` (document icon)
- Label: "Export" — DM Sans Regular 13pt
- Style: plain toolbar button, ColorTokens.text1 tint
- Placement: trailing toolbar position

### PDF Document Layout (UIGraphicsPDFRenderer)

Page size: US Letter — 612 x 792 points (8.5 x 11 inches at 72 DPI). Source: D-06.

#### Page Structure

```
+--------------------------------------------------+
| 48pt left margin                    48pt right    |
|                                                   |
| 64pt top margin                                   |
|                                                   |
| [Tonus]                    [Athlete Name]         |
| 15pt Medium                [Apr 1 - Apr 25, 2026] |
|                            13pt Regular            |
|                                                   |
| ─── 0.5pt divider ───────────────────────────     |
|                                                   |
| CONTENT AREA                                      |
| (516pt wide = 612 - 48 - 48)                     |
|                                                   |
|                                                   |
| ─── footer divider ──────────────────────────     |
| Page 1                     Generated by Tonus     |
| 11pt Regular               11pt Regular           |
|                                                   |
| 64pt bottom margin                                |
+--------------------------------------------------+
```

Content area height: 792 - 64 - 64 - 48 (header) - 24 (footer) = 592pt usable per page.

#### Athlete Report Sections (D-02, D-03)

**Section 1: Key Metrics Header**
- Layout: 5-column grid across content width (516pt / 5 = ~103pt each)
- Each cell: metric value (28pt Regular, #7A6E5C accent) centered, label (11pt Regular uppercase, #696560) below
- Metrics: Recovery Score, ACWR Zone, Streak, Sessions, PRs
- 24pt padding below section, 0.5pt divider below

**Section 2: Recovery Overview**
- Section title: "RECOVERY OVERVIEW" — 17pt Medium, #1C1915
- Trend line chart: 516pt wide x 120pt tall, drawn with Core Graphics CGPath
  - X-axis: dates (11pt Regular, #696560)
  - Y-axis: score 0-100 (11pt Regular, #696560)
  - Line: 1.5pt stroke, #3E5C49 (zone optimal color)
  - No fill under line
- Below chart: current score callout + sleep/HRV composite summary text (13pt Regular)
- 32pt gap before next section

**Section 3: Workload Trends**
- Section title: "WORKLOAD TRENDS" — 17pt Medium, #1C1915
- Dual-line chart: 516pt wide x 120pt tall
  - ATL line: 1.5pt, #6B5828
  - CTL line: 1.5pt, #3A4A5C
  - Legend: two items below chart, 11pt Regular with colored line indicators
- Current zone text: "Current zone: Optimal" with zone color 0.5pt border box
- 32pt gap before next section

**Section 4: Session Log**
- Section title: "SESSION LOG" — 17pt Medium, #1C1915
- Table columns: Date (90pt) | Sport (80pt) | Duration (70pt) | RPE (50pt) | Load (70pt) | ACWR (70pt)
  - Remaining width (86pt) absorbed proportionally
- Header row: 11pt Medium uppercase, #696560, 0.5pt bottom border
- Data rows: 13pt Regular, #1C1915, 0.5pt bottom border, 24pt row height
- Alternating row background: none (clean white). Rows separated by hairline only.
- Page break if table exceeds remaining space: continue on next page with header row repeated

**Section 5: Personal Records**
- Section title: "PERSONAL RECORDS" — 17pt Medium, #1C1915
- Table columns: Exercise (200pt) | Type (80pt) | Value (120pt) | Date (116pt)
- Same table styling as session log
- If no PRs in period: "No personal records achieved in this period." — 13pt Regular, #696560, italic

#### Coach Roster Report (D-08)

Single-page summary (or multi-page if many athletes).

**Header:** Same branded header but title reads "Roster Summary" instead of "Training Report".

**Roster Table:**
- Columns: Athlete (140pt) | Recovery (80pt) | ACWR (70pt) | Zone (80pt) | Sessions (70pt) | Streak (50pt) | Flag (26pt)
- Header: 11pt Medium uppercase
- Data: 13pt Regular
- Flag column: SF Symbol equivalent drawn as text -- "!" character in #6E3A3A if athlete is in danger/overreaching zone, empty otherwise
- Row height: 24pt
- 0.5pt hairline borders

## Interaction Patterns

### Export Flow — Athlete

1. User taps export button in WorkloadView toolbar
2. confirmationDialog appears with CSV and PDF options
3. If user taps "PDF Report (Pro)":
   a. If not Pro: UpgradeSheet presented, flow ends
   b. If Pro: PDF Generation Sheet slides up
4. User selects date range via chips (default: "Last 4 weeks")
5. User taps "Generate Report"
6. Loading state: button shows "Generating..." with spinner
7. PDF generated in background, written to temp directory
8. ShareSheet presented with PDF file URL
9. User shares/saves via system share sheet
10. Sheet dismissed, back to WorkloadView

### Export Flow — Coach

1. Coach taps "Export" in CoachRosterView toolbar
2. If not Coach entitlement: UpgradeSheet presented, flow ends
3. Athlete Picker Sheet slides up
4. All athletes pre-selected by default
5. Coach toggles individual athletes or uses "Select All" / "Deselect All"
6. Coach selects date range via chips
7. Coach taps "Generate Roster Report"
8. Loading state on button
9. PDF generated, ShareSheet presented
10. Sheet dismissed

### State Transitions

| State | Trigger | UI Change |
|-------|---------|-----------|
| Idle | User opens export dialog | confirmationDialog shows |
| Format selected | User taps "PDF Report (Pro)" | Sheet slides up with date range + CTA |
| Generating | User taps "Generate Report" | CTA disabled, label changes to "Generating...", ProgressView appears |
| Complete | PDF written to temp | ShareSheet presented automatically |
| Error | Generation fails | Alert with error message, CTA re-enabled |
| Gated | Free user taps PDF option | UpgradeSheet presented |

## Accessibility

- All date range chips have accessibility labels: "Last 4 weeks, selected" / "Last 8 weeks"
- Export buttons have accessibility hints: "Generates a PDF report of your training data"
- Coach athlete picker checkmarks: accessibility value "selected" / "not selected"
- PDF document: tagged PDF not required for v1.1, but text is real text (not rasterized) for copy-paste accessibility
- Loading state: ProgressView announces via VoiceOver automatically
- Minimum touch target: 44pt on all interactive elements (chips, buttons, checkmarks)
