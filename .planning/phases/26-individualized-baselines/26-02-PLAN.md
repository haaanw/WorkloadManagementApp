Exact recurrences (RESEARCH §1–§4 — implement verbatim, cited textbook forms):
- λ from half-life H: `λ = 1 − pow(2.0, -1.0 / H)` (§1.1). lambda(halfLifeDays: .infinity) → 0.
- EWMA fold (§1.1): `μ_t = (1−λ)·μ_{t-1} + λ·ŷ_t` where ŷ_t is the Huber-CLIPPED observation.
- Welford M2 (§1.2, numerically stable — NEVER naive Σx²−(Σx)²/n): delta = ŷ−welfordMean; welfordMean += delta/count; delta2 = ŷ−welfordMean; m2 += delta·delta2; σ_welford = sqrt(m2/(count−1)) for count≥2.
- Rolling MAD (§1.2, PRIMARY scale): over the madBuffer of last W=21 raw innovations: m = median(buf); MAD = median(|r−m|); σ_mad = 1.4826·MAD. Active scale σ = max(σ_mad, σ_floor); use σ_welford only as cold-start fill while buffer < W_min(=5).
- Huber clip (§1.3): r = y − μ_{t-1}; r̂ = clamp(r, −k·σ, +k·σ); ŷ = μ_{t-1} + r̂. k = 1.5 (huberK).
- z (§2): innovation r = y − μ_{t-1}; z = r / max(σ_mad, σ_floor) using σ from state through t-1; nil if count<2 OR madBuffer.count < W_min. Sign convention: HRV positive-is-good as-is; RHR negate so +z = better (caller passes a sign or the engine takes a `higherIsBetter: Bool`).
- CV (§3): recentScale = 1.4826·median(|r| over last N_short=7); baselineScale = 1.4826·median(|r| over last N_long=28); cvRatio = recentScale / max(baselineScale, σ_floor). 3-level hysteresis: HIGH when ratio≥1.5 AND ≥14 valid in long window; ELEVATED when ≥1.25; CLEAR to NORMAL when ≤1.10; suppressed (normal) when valid < cvShortMin=7.
- Confidence (§4): c_count = clamp01((count−floorDays)/(fullDays−floorDays)); c_recency = exp(−daysSinceLastBucket/τ_recency) (and ≈0 beyond staleHardCutDays); c_disp = clamp01(1 − (cvRatio−1)/dispSpan); confidence = c_count·c_recency·c_disp. clamp01(x)=min(1,max(0,x)).
