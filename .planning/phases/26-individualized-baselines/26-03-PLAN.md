BucketedDay shape (RESEARCH §5): `struct BucketedDay { let date: Date /* startOfDay */; let value: Double? /* nil = GAP */ }`, ascending by date.

Bucketing rules (D-02 / D-02a / §5.1–5.4):
- HRV/RHR: group samples by `calendar.startOfDay(of: sample.date)`; within each day keep only samples whose hour < morningWindowEndHour (=11); the day's value = MEDIAN of those in-window samples; no in-window sample ⇒ that day is a GAP (value nil). Median-of-one degrades to that value.
- Sleep: one (value,date) per night ⇒ bucket by `startOfDay(of: date)`, value = the aggregate minutes.
- Dedup: never emit the same physical (date,value) twice; a "latest" sample whose startOfDay < the target day does NOT fill the target day (target day = GAP). The day-grouping naturally dedups intra-day; the stale guard is the cross-day rule.
- Output spans the requested day range ascending, emitting GAP days for missing days so daysSinceLastBucket can be computed downstream (the engine/caller advances recency over GAPs).

Constant: `morningWindowEndHour = 11` is a named constant (reuse BaselineConstants from Plan 02 if exposed there, else define alongside DayBucketer). Tunable.
