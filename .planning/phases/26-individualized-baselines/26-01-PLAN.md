<objective>
Lay the persistence foundation for the robust individualized-baseline substrate: a new dedicated, **local-only never-synced** `BaselineState` SwiftData `@Model` holding the per-athlete running state for all three signals (HRV / RHR / sleep) as flattened sub-states. Output: `BaselineState.swift` (local-only @Model), Schema registration, and persistence + sync-omission tests — all build-green with correct `.pbxproj` target membership. This plan resolves the researcher's open question #2 (one row, flattened) by decision.
