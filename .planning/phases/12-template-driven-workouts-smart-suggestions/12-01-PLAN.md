**2. Create TemplateSuggestionEngine.swift:**

Follow the AutoregulationEngine pattern: `import Foundation` only, pure struct with static methods, nested input/output types.

**Struct and nested types:**
```swift
struct TemplateSuggestionEngine {
    struct SuggestionResult {
        let template: WorkoutTemplate
        let isRecoveryAdjusted: Bool
        let rationale: String
    }
}
```

**Primary method -- `suggest()`:**
```swift
static func suggest(
    templates: [WorkoutTemplate],
    recentSessions: [WorkoutSession],
    currentRecoveryZone: RecoveryZone,
    today: Date = .now
) -> SuggestionResult?
```

Logic (per D-15, D-16, D-17, D-18):
1. Guard `templates.count > 0`, else return nil
2. Filter sessions to last 2 weeks. If fewer than 3 sessions in that window, return nil (insufficient data per D-16)
3. Get today's ISO weekday via `isoWeekday(from:)` helper (copy Apple-to-ISO conversion from TemplateCarouselSection: `apple == 1 ? 7 : apple - 1`)
4. Call `pickByFrequency(templates:sessions:weekday:)` to find the template most used on today's weekday
5. If no frequency match found, return nil (silent fallback to Phase 11 centering per D-16)
6. Recovery check (D-17, D-18): if `currentRecoveryZone == .red || currentRecoveryZone == .yellow`, call `findLighterAlternative(current:all:sessions:)`. If lighter found, return SuggestionResult with `isRecoveryAdjusted: true` and rationale "Recovery-adjusted: lighter session suggested". If no lighter alternative (only one template or no lighter option), still return the frequency pick with `isRecoveryAdjusted: false`
7. Return SuggestionResult with `isRecoveryAdjusted: false` and rationale "Based on your {weekdayName} training pattern"

**Helper -- `pickByFrequency()`:**
```swift
private static func pickByFrequency(
    templates: [WorkoutTemplate],
    sessions: [WorkoutSession],
    weekday: Int
) -> WorkoutTemplate?
```
- Build frequency map: `[UUID: [Int: Int]]` (templateId -> weekday -> count)
- Match sessions to templates via `session.sourceTemplateId` (primary) or `session.sessionName == template.templateName` (fallback for sessions created before sourceTemplateId existed)
- For the target weekday, find the template with highest count
- Return nil if no template has any sessions on this weekday

**Helper -- `findLighterAlternative()`:**
```swift
private static func findLighterAlternative(
    current: WorkoutTemplate,
    all: [WorkoutTemplate],
    sessions: [WorkoutSession]
) -> WorkoutTemplate?
```
- Exclude the current template and archived templates
- Primary heuristic: compare exercise count (fewer exercises = lighter) -- use `template.sortedGroups.flatMap { $0.sortedExercises }.count`
- Secondary heuristic (when exercise counts tie): compare average historical trainingStress from sessions linked to each template
- Return the template with the lowest exercise count (or lowest average TSS if tied)
- Return nil if no alternative exists or all alternatives have equal/higher exercise count

**Helper -- `isoWeekday(from:)`:**
```swift
static func isoWeekday(from date: Date) -> Int {
    let apple = Calendar.current.component(.weekday, from: date)
    return apple == 1 ? 7 : apple - 1
}
```

**Helper -- `weekdayName(_:)`:**
```swift
private static func weekdayName(_ iso: Int) -> String {
    let names = ["Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday", "Sunday"]
    return names[max(0, min(6, iso - 1))]
}
```
