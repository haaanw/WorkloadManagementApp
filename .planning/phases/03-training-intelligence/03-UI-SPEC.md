## Color

All colors via `ColorTokens` enum. Never hardcode hex in views. Supports dark + light mode automatically.

| Role | Dark Hex | Light Hex | Usage |
|------|----------|-----------|-------|
| Dominant (60%) — background | #0B0B0A | #F4F1ED | App background, ScrollView fill |
| Secondary (30%) — surface | #131312 | #EDEAE6 | Cards, insight cards, chip selected background |
| Accent (10%) | #A8A090 | #7A6E5C | Hero readiness score number ONLY |
| Divider | #232321 | #CFCBC5 | Hairline separators (0.5pt), chip unselected border |
| Text primary | #C2BEB7 | #1C1915 | Body copy, selected chip label, insight text |
| Text secondary | #7C7972 | #696560 | Phase label, unselected chip label, encouragement text |
| Text tertiary | #3A3835 | #AFABA5 | Section micro headers ("INSIGHTS", "BEHAVIORS") |
| Zone optimal | #607869 | #3E5C49 | Positive behavior correlation border (recovery improved) |
| Zone danger | #7E5C5C | #6E3A3A | Negative behavior correlation border (recovery worsened) |

Accent reserved for: the hero readiness score number (56pt). Nowhere else. The periodization phase label, insight cards, behavior chips, and correlation percentages all use `text1` / `text2` only.

### Correlation Color Rule

Behavior correlation cards use a 0.5pt left border to indicate direction:
- Positive impact (recovery improved with tag): `ColorTokens.zoneOptimal` left border
- Negative impact (recovery worsened with tag): `ColorTokens.zoneDanger` left border
- The percentage number itself uses `ColorTokens.text1` -- never colored

This follows the existing zone color rule: "color is supplementary, not the sole information channel." The direction is always stated in text ("Recovery +8% on days with caffeine").

## Component Specifications

### DataSufficiencyRing

**Purpose:** Circular progress indicator gating intelligence features behind minimum data thresholds.

**Dimensions:**
- Ring outer diameter: 48pt
- Ring stroke width: 2pt
- Track (background circle): `ColorTokens.divider`, 2pt stroke
- Progress arc: `ColorTokens.text2`, 2pt stroke
- Rotation: starts at 12 o'clock (`.rotationEffect(.degrees(-90))`)
- Container padding: 16pt all sides

**Layout (vertical stack, 16pt spacing):**
1. Circle ring (48x48pt)
2. Counter label: "3 of 8 weeks" -- `.Tokens.label`, `ColorTokens.text1`
3. Encouragement text: multiline, centered -- `.Tokens.label`, `ColorTokens.text2`

**States:**
- Periodization gate: progress = weeksAvailable / 8, label = "{N} of 8 weeks", message = "Keep logging -- periodization insights unlock after 8 weeks of consistent training"
- Behavior correlation gate: progress = min(daysWithTag, daysWithoutTag) / 5, label = "{N} more tagged days needed", message = "Tag behaviors daily to see recovery impact"

**When shown:**
- Dashboard hero card: replaces phase label when `sufficiency.isSufficient == false`
- Recovery insights section: replaces insight cards when insufficient data

### BehaviorTagChip

**Purpose:** Toggle chip for daily behavior tagging in wellness check-in.

**Dimensions:**
- Horizontal padding: 16pt
- Vertical padding: 8pt
- Border radius: 0pt (Rectangle, not RoundedRectangle)
- Border: 0.5pt `ColorTokens.divider` (unselected), 0.5pt `ColorTokens.text2` (selected)

**States:**
- Unselected: `ColorTokens.background` fill, `ColorTokens.text2` label, `ColorTokens.divider` border
- Selected: `ColorTokens.surface` fill, `ColorTokens.text1` label, `ColorTokens.text2` border

**Layout in MorningCheckInSheet:**
- Positioned between Stress slider and Notes field
- Section header: "BEHAVIORS" in `.Tokens.micro` + `.tracking(1.2)` + `ColorTokens.text3`
- Chips wrapped in horizontal flow using `HStack` with `FlexibleGrid` or manual wrapping at screen edge
- Horizontal padding: 16pt (matches other sections)
- Vertical padding: 16pt top, 16pt bottom
- Chip-to-chip gap: 8pt horizontal, 8pt vertical
- Default 4 chips: "Caffeine", "Alcohol", "Travel", "Stress"
- Pro users see "Manage Tags" button after chips -- `.Tokens.label`, `ColorTokens.text2`, tappable

**No animation on toggle.** Instant state change (follows D-02 silent update principle).

### InsightCard

**Purpose:** Natural language fatigue pattern insight from FatiguePatternEngine.

**Dimensions:**
- Full width (screen width minus 16pt horizontal margins)
- Vertical padding: 16pt
- Horizontal padding: 16pt
- Background: `ColorTokens.surface`
- Bottom border: 0.5pt `ColorTokens.divider`

**Layout (vertical stack, 8pt spacing):**
1. Insight text: `.Tokens.body`, `ColorTokens.text1` -- e.g. "Recovery typically drops 2 days after high-volume upper body sessions"
2. Confidence note: `.Tokens.label`, `ColorTokens.text2` -- e.g. "Based on 12 occurrences"

**Ordering:** Cards sorted by confidence descending. Maximum 5 cards shown.

**No icons, no color coding on insight text.** Pure text hierarchy. Follows ReasoningEngine.Factor display pattern.

### BehaviorCorrelationRow

**Purpose:** Shows recovery impact percentage for a single behavior tag.

**Dimensions:**
- Full width, 16pt horizontal padding, 16pt vertical padding
- Left border: 3pt width, `zoneOptimal` (positive) or `zoneDanger` (negative)
- Background: `ColorTokens.surface`
- Bottom separator: 0.5pt `ColorTokens.divider`

**Layout (horizontal, space-between):**
- Left side (vertical, 8pt spacing):
  1. Tag name: `.Tokens.body`, `ColorTokens.text1` -- "Caffeine"
  2. Direction text: `.Tokens.label`, `ColorTokens.text2` -- "Recovery +8% on tagged days"
  3. Sample size: `.Tokens.label`, `ColorTokens.text2` -- "12 days with, 18 days without"
- Right side:
  1. Percentage: `.Tokens.sectionHead`, `.monospacedDigit()`, `ColorTokens.text1` -- "+8%"

**States:**
- Sufficient data (5+ yes AND 5+ no): show full correlation row
- Insufficient data: show tag name + progress text ("3 more tagged days needed") -- no correlation value

## Interaction Contracts

### Dashboard Hero Card -- Phase Label

**Trigger:** `DashboardViewModel.load()` calls `PeriodizationEngine.checkSufficiency()` and `PeriodizationEngine.detectPhase()`.

**Display logic:**
1. If `sufficiency.isSufficient == true` AND `phase != nil`: show phase label text directly below the 56pt score number
2. If `sufficiency.isSufficient == false`: show DataSufficiencyRing below the score number
3. If no sessions at all (brand new user): show nothing (existing EmptyStateCard handles this)

**Phase label position:** Directly below the score number, above the first hairline divider. No additional spacing beyond the VStack's existing 16pt spacing.

**Phase label does NOT animate or transition.** Silent update per D-02.

### Morning Check-in -- Behavior Tags

**Trigger:** User opens MorningCheckInSheet from Recovery tab.

**Flow:**
1. Existing sliders render (Sleep, Soreness, Energy, Stress)
2. NEW: "BEHAVIORS" section with toggle chips appears between Stress slider and Notes field
3. User taps chips to toggle on/off (instant, no animation)
4. On save: behavior tags persisted as BehaviorTag records linked to WellnessCheckIn
5. Default tags always shown; custom tags (Pro) shown after defaults

**Pro gate for custom tags:**
- Non-Pro users: 4 default chips only, no "Manage Tags" button
- Pro users: 4 default chips + any custom tags + "Manage Tags" button at end

**Custom Tag Management (Pro only):**
- Tapping "Manage Tags" presents a sheet with:
  - List of custom tags with swipe-to-delete
  - "Add Tag" row at bottom with inline text field
  - Maximum 8 custom tags (12 total with defaults)
  - Tag name maximum 20 characters

### Recovery Tab -- Insights Section

**Trigger:** `RecoveryViewModel.load()` calls `FatiguePatternEngine.detectPatterns()` and `BehaviorCorrelationEngine.computeCorrelations()`.

**Position:** Below SleepTrendChart, separated by hairline divider.

**Section layout:**
1. "INSIGHTS" header in `.Tokens.micro` format (matches "THIS WEEK" header pattern)
2. Fatigue insight cards (InsightCard components, max 5)
3. Hairline divider
4. "BEHAVIOR IMPACT" header in `.Tokens.micro` format
5. Behavior correlation rows (BehaviorCorrelationRow, one per tag with sufficient data)
6. Tags with insufficient data shown with progress text below correlations

**Empty state (no insights yet):**
- DataSufficiencyRing with periodization or behavior-specific message
- One ring per gate (periodization and behavior shown separately if both insufficient)

**Section is NOT collapsible** (unlike WeeklySummaryCard). Always expanded when data exists.

## State Matrix

| View | State | What Renders |
|------|-------|-------------|
| Dashboard hero | Phase detected, sufficient data | Phase label text below score |
| Dashboard hero | Insufficient data (<8 weeks) | DataSufficiencyRing below score |
| Dashboard hero | No sessions at all | Existing EmptyStateCard (no phase UI) |
| Dashboard hero | Loading | Existing loading state (no phase UI) |
| Recovery insights | Fatigue patterns found | InsightCard list (max 5) |
| Recovery insights | No patterns (insufficient data) | DataSufficiencyRing for periodization |
| Recovery insights | Behavior correlations ready | BehaviorCorrelationRow per tag |
| Recovery insights | Behavior tags insufficient | Tag name + "{N} more tagged days needed" |
| Recovery insights | No behavior tags logged ever | "Tag behaviors in your morning check-in to see recovery impact" |
| MorningCheckInSheet | Default user | 4 default behavior chips |
| MorningCheckInSheet | Pro user | 4 default chips + custom chips + "Manage Tags" |
| MorningCheckInSheet | Pro user, no custom tags yet | 4 default chips + "Manage Tags" |
| Custom tag management | Tags exist | List with swipe-to-delete + add row |
| Custom tag management | No custom tags yet | "Add Tag" row only |
| Custom tag management | Limit reached (8 custom) | "Add Tag" row disabled + limit message |
