|------|------|--------|-------------|-------------|
| Section head | 19pt | 500 (Medium) | 1.4 | --text-1 |

## Phase 14 UI Components

This phase has minimal UI surface. Two new elements.

**Focal points:**
- **Discovery trigger:** Sync health dot badge on Profile tab icon -- draws attention to sync issues.
- **Per-row anchor:** Leading status indicator circle in each entity row -- immediate pass/fail signal per entity.

### 1. Sync Health Dot Badge (Profile Tab Icon)

**Focal point:** This dot badge is the discovery trigger -- the single element that alerts the user to navigate into sync status details.

**Location:** Profile tab bar item, top-trailing corner of the SF Symbol icon.

**Behavior:**
- Visible when any `SyncEntity` has a failed last sync attempt (error stored in memory or UserDefaults)
- Hidden when all entity types have succeeded on their last sync
- No animation on appearance -- simply present or absent (150ms linear fade per DESIGN.md motion rules)

**Visual spec:**
- Shape: `Circle()` -- 8pt diameter (grid-aligned)
- Fill: `ColorTokens.zoneCaution` (barely-amber, same as ACWR caution zone)
- Position: offset(x: 8, y: -8) from tab icon center
- No border, no shadow, no pulse animation

### 2. Sync Status Detail View

**Location:** New section within ProfileView, below existing profile settings. Accessible by tapping a "Sync Status" row.

**Layout:** Single scrollable list of entity rows within a card container.

**Card container:**
- `Rectangle().fill(ColorTokens.surface)` with `ColorTokens.divider` 0.5pt border overlay
- 0pt corner radius
- 16pt horizontal padding, 24pt vertical padding

**Section header:**
- Text: "SYNC STATUS" -- Alpino Regular, 13pt, `ColorTokens.text2`, letter-spacing +0.08em, all-caps
- 8pt bottom margin before first row

**Entity row (repeated for each of 10 SyncEntity types):**

**Focal point:** The leading status indicator circle is the per-row anchor -- immediate visual signal of pass/fail state for each entity.

- Height: 48pt (fits touch target)
- Layout: HStack with 8pt spacing
  - Leading: Status indicator circle -- 8pt diameter, filled `zoneCaution` (failed) or `zoneOptimal` (succeeded)
  - Center VStack (aligned leading):
    - Entity name: Alpino Regular, 15pt, `ColorTokens.text1` -- e.g. "Workouts", "Templates", "Personal Records"
    - Last synced timestamp: Alpino Regular, 13pt, `ColorTokens.text2` -- relative time format ("2 min ago", "3 hours ago", "Never")
  - Trailing (only when failed): Error summary text, Alpino Regular, 13pt, `ColorTokens.zoneCaution`, max 1 line, truncated
- Divider between rows: `ColorTokens.divider`, 0.5pt height, full width minus 16pt leading inset

**All synced state:**
- When all 10 entities show success, the section header row in ProfileView displays "All data synced" as the detail label in `ColorTokens.text2`, 15pt
- No badge on Profile tab

**Profile row (navigation entry point):**
- Follows existing ProfileView row pattern
- Leading icon: `arrow.triangle.2.circlepath` (SF Symbol) in `ColorTokens.text2`
- Text: "Sync Status" -- Alpino Regular, 17pt, `ColorTokens.text1`
- Detail: relative time of oldest successful sync OR "Issues" in `ColorTokens.zoneCaution` if any entity failed
- Trailing: chevron.right in `ColorTokens.text3`

## Interaction Contracts

| Interaction | Behavior |
|-------------|----------|
| Tap "Sync Status" row in Profile | Navigate to SyncStatusView (push on NavigationStack) |
| Pull-to-refresh on SyncStatusView | Trigger immediate foreground sync for all entities, update timestamps on completion |
| Sync completes in background | Dot badge appears/disappears with 150ms linear fade |
| App returns to foreground | Normal sync cycle runs; badge updates based on results |
