<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UserDefaults → LocaleManager | Untrusted local persistence (debug tooling, profile manipulation) crosses into in-app state |
| ProcessInfo arguments → AppRouter SCREENSHOT_MODE branch | Launch args influence locale state (limited to DEBUG / TestFlight builds with this scheme) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-01 | Tampering | LocaleManager UserDefaults read | mitigate | Whitelist read identifier against `supportedLocales.map(\\.identifier)`; on mismatch fall back to system-default path (RESEARCH §"Security Domain" V5) |
| T-23-02 | Tampering | Catalog key construction | mitigate | All `String(localized:)` calls must use literal keys — no `\\(userInput)` interpolation. P2/P4 enforce via grep gate; P1 only constructs literal keys (`language.picker.title`, `onboarding.language.title`, etc.) |
| T-23-03 | Information Disclosure | Selected language identifier | accept | Local-only state in UserDefaults; never synced to Supabase, never sent to RevenueCat; no PII (RESEARCH §"Privacy") |
| T-23-04 | Spoofing | SCREENSHOT_MODE locale override | accept | Gated by DEBUG build + explicit launch argument; production builds cannot reach this path |
</threat_model>
