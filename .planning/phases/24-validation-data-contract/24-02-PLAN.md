<objective>
Upgrade the shadow harness beyond MAE-only by adding the validation metrics both codex reviews demanded **before** any model code: a **calibration slope**, **Spearman ρ**, **blocked/purged cross-validation** splitting, and a **block-bootstrap confidence interval** for the paired MAE difference between two arms that respects daily autocorrelation. This phase computes the *machinery* — the numeric activation gates (MAE beat ≥3/4, ρ≥0.50, slope∈[0.8,1.2]) are *applied* in Phase 29, not here.

No scoring model, no baselines, no behavior change. The metrics run over the existing two arms' resolved predictions; with little history they will frequently and correctly return `insufficientData`. Master activation flag stays OFF.
</objective>

  <behavior>
    - `blockedCVSplits(count: Int, folds: Int, purge: Int) -> [(train: Range<Int>, test: Range<Int>)]` (or index sets): partitions `0..<count` into `folds` contiguous, time-ordered test blocks; the train side excludes a `purge`-wide gap (>= prediction horizon) around each test block; NO random shuffling
    - Worked example: count 20, folds 4, purge 1 → four contiguous 5-wide test blocks; train indices for a middle block exclude the block AND the 1-index purge gap on each side
    - Degenerate: folds <= 1 or count too small for the requested folds+purge → returns a single full-data fold or `[]` per a documented rule (never crash)
    - `pairedMAEDifferenceBlockBootstrapCI(armA: [(pred,actual)], armB: [(pred,actual)], blockLength: Int, resamples: Int, alpha: Double, seed: UInt64) -> (lower: Double, upper: Double, point: Double)?`
    - It resamples CONTIGUOUS blocks of length `blockLength` (moving-block bootstrap) over the time-ordered per-row paired absolute errors (errA - errB), rebuilding a series of the bootstrap length, computing the mean paired-MAE-difference per resample, and returning the empirical [alpha/2, 1-alpha/2] quantiles + the observed point estimate
    - Determinism: same `seed` → identical CI (uses a seedable PRNG, e.g. SplitMix64, NOT SystemRandomNumberGenerator)
    - Graceful: n < blockLength or n < 2 → nil
    - Significance semantics test: a fixture where armB is uniformly better (errB < errA every row) yields a CI for (errA-errB) strictly > 0 (excludes 0); a noise fixture yields a CI straddling 0
  </behavior>
  <action>
    Add to `ShadowMetrics`: (1) `blockedCVSplits(count:folds:purge:)` producing contiguous time-ordered test blocks with a purge gap on the train side (default purge = prediction horizon = 1), no random split — return index ranges/sets and a documented degenerate rule. (2) A seedable PRNG (small SplitMix64 `RandomNumberGenerator` conformer, private to the file) so the bootstrap is deterministic. (3) `pairedMAEDifferenceBlockBootstrapCI(...)` implementing a **moving-block bootstrap**: form the per-row paired error difference `d_i = |predA_i-actual_i| - |predB_i-actual_i|`, resample contiguous blocks of `blockLength` to reconstruct ~n samples per resample, take each resample's mean `d`, repeat `resamples` times, and return the (alpha/2, 1-alpha/2) empirical quantiles + the full-sample point estimate. Guards → nil. Add tests: the CV worked example (count 20/folds 4/purge 1 partition + purge-gap exclusion), the degenerate CV rule, the deterministic-seed CI equality (same seed twice → equal), the uniformly-better → CI excludes 0, and the noise → CI straddles 0 fixtures.
