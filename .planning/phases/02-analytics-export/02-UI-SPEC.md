## Spacing Scale

All values multiples of 8pt per DESIGN.md:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 8pt | Icon-label gaps, inline spacing, icon padding |
| sm | 16pt | Card internal horizontal padding, small gaps, horizontal margins |
| md | 24pt | Card internal vertical padding, standard section gaps |
| lg | 32pt | Section gaps between major content blocks |
| xl | 48pt | Major section breaks |
| 2xl | 64pt | Page-level top/bottom breathing room |

Exceptions: Segmented control internal padding uses 8pt horizontal / 8pt vertical per segment for touch target sizing. Chart tooltip offset uses 8pt from data point.

## Interaction Contracts

### Time Range Picker (D-01)

- **Placement:** Directly above trend chart area on Workload tab, 16pt horizontal margin
- **Behavior:** Tap segment to switch; chart data animates with 250ms easeOut transition
- **Default selection:** 4W (most recent, least data needed)
- **Visual:** `surface` background on selected segment, `background` on unselected, `divider` border around entire control, 0pt corner radius

### Chart Tooltip (D-02)

- **Trigger:** Tap and hold on chart area; drag finger to scrub across data points
- **Display:** `surfaceEl` rectangle (0pt corners) positioned 8pt above the data point, showing value in `body` font (text1) and date in `label` font (text2)
- **Dismiss:** Lift finger
- **Implementation:** Swift Charts `.chartOverlay` with `DragGesture`

### Weekly Summary Collapse (D-03)

- **Default state:** Expanded on first visit, remembers collapse state
- **Toggle:** Tap section header row (entire row is tappable)
- **Animation:** 250ms easeOut height transition
- **Chevron:** SF Symbol `chevron.down` rotates 180 degrees on collapse, tinted `text3`

### Delta Indicators (D-04)

- **Positive delta:** `arrow.up` SF Symbol + "+X%" in `zoneOptimal` color
- **Negative delta:** `arrow.down` SF Symbol + "-X%" in `zoneDanger` color
- **Zero/negligible (less than 1%):** em dash in `text2`, no arrow
- **Placement:** Trailing edge of each metric in weekly summary

### Staleness Warning (D-05, D-06)

- **Threshold:** 24 hours since last HRV or sleep reading
- **Placement:** Inline within affected metric tile (HRV, RHR, Sleep on Dashboard MetricsStrip)
- **Non-blocking:** User still sees last known values; warning is additive
- **Copy format:** "Updated 2d ago" (relative time, abbreviated)
- **Icon:** SF Symbol `exclamationmark.triangle.fill` at 13pt, `zoneCaution` tint

### CSV Export Flow (D-07, D-08)

- **Entry point:** Toolbar button on Workload tab (SF Symbol `square.and.arrow.up`, tinted `text1`)
- **Step 1:** Tap button -> action sheet appears with two options + Cancel
- **Step 2:** User selects format -> CSV generated in background -> system share sheet presented
- **Pro gate:** If not Pro, tapping export shows `UpgradeSheet(trigger: .export)` instead of action sheet
- **Loading state:** Brief activity indicator while CSV generates (expected < 1 second)

### Recovery-Load Correlation (ANLYT-04)

- **Layout:** Full-width chart, 28-day fixed window, 180pt height
- **Bar layer:** Daily load as BarMark, `chartVolume` fill
- **Line layer:** Recovery score as LineMark overlay, `zoneOptimal` stroke, 1.5pt line width
- **Y-axes:** Left axis = load (auto-scaled), right axis = recovery score (0-100 fixed)
- **Tooltip:** Same tap-scrub pattern as trend charts (D-02)

## Accessibility

- All chart data accessible via VoiceOver custom rotor (Swift Charts provides this by default)
- Staleness warning has accessible label: "Warning: health data last updated X days ago"
- Delta indicators have accessible labels: "Volume increased 12 percent week over week"
- Zone badges already use text labels as primary information channel (per DESIGN.md zone color rule)
- Segmented control uses native Picker with `.pickerStyle(.segmented)` for built-in accessibility
- Export button has accessible label: "Export workout data"
- All numeric values use `.monospacedDigit()` for layout stability
