**Part A: TemplateEditorSheet prefill init (per D-06, Pitfall 6)**

Add a second convenience init to TemplateEditorSheet that accepts pre-built draft data for LLM import. Do NOT remove or modify the existing init.

```swift
/// Convenience init for LLM import pre-fill (D-06)
init(
    coachId: UUID,
    prefillName: String,
    prefillSportType: SportType,
    prefillSessionType: SessionType,
    prefillGroups: [GroupDraft]
) {
    self.coachId = coachId
    self.existingTemplate = nil
    self._templateName = State(initialValue: prefillName)
    self._sportType = State(initialValue: prefillSportType)
    self._sessionType = State(initialValue: prefillSessionType)
    self._groups = State(initialValue: prefillGroups.isEmpty ? [GroupDraft(groupName: "Main")] : prefillGroups)
}
```

This uses `State(initialValue:)` to set initial @State values from the init, bypassing `loadExisting()` (which only fires when `existingTemplate` is non-nil). The existing init and `loadExisting()` remain untouched.

**Part B: WorkoutImportSheet (per D-01, D-02, D-08, D-09)**

Create `WorkloadApp/Views/WorkoutLog/WorkoutImportSheet.swift` as a SwiftUI view. Structure:

1. **State:**
   - `@Environment(AppContainer.self) private var container`
   - `@Environment(\.dismiss) private var dismiss`
   - `@Query private var athletes: [Athlete]`

   - `@State private var inputText = ""`
   - `@State private var isLoading = false`
   - `@State private var errorMessage: String?`
   - `@State private var showEditor = false`
   - `@State private var parsedName = ""`
   - `@State private var parsedSportType: SportType = .lifting`
   - `@State private var parsedSessionType: SessionType = .strength`
   - `@State private var parsedGroups: [GroupDraft] = []`
   - `@State private var showDocumentPicker = false`
   - `@State private var showPhotoPicker = false`
   - `@State private var showCamera = false`
   - `@State private var selectedPhotoItem: PhotosPickerItem?`

2. **ImportTab enum:** Three cases with displayName and systemImage properties.

3. **Body layout:**
   - `NavigationStack` with title "Import Workout" (inline).
   - Cancel button in toolbar (cancellationAction).
   - Custom segmented picker at top using three buttons styled per design system (0pt corners, hairline borders, ColorTokens). The selected tab uses `ColorTokens.surface` background with `ColorTokens.text1` text, unselected uses `ColorTokens.background` with `ColorTokens.text2`.
   - Below picker, content switches by `selectedTab`:

   **Text tab (D-02):**
   - Instruction label: "Paste any workout text below" in `.Tokens.label`, `ColorTokens.text2`.
   - `TextEditor(text: $inputText)` with `.font(.Tokens.body)`, min height 200, hairline border overlay (`Rectangle().stroke(ColorTokens.divider, lineWidth: 0.5)`).
   - "Parse Workout" button: full-width, `.font(.Tokens.body)`, `ColorTokens.text1`, hairline border, disabled when text is empty or `isLoading`.

   **PDF tab (D-02):**
   - Instruction text: "Select a PDF file containing your workout" in `.Tokens.label`, `ColorTokens.text2`.
   - "Choose PDF" button: full-width, same styling as Parse button.
   - Uses `.fileImporter(isPresented: $showDocumentPicker, allowedContentTypes: [.pdf])` modifier.
   - On selection: call `handlePDFImport(url:)`.

   **Photo tab (D-02):**
   - Instruction text: "Take a photo of a workout or choose from your library" in `.Tokens.label`, `ColorTokens.text2`.
   - Two buttons side by side: "Camera" (SF Symbol: camera) and "Photo Library" (SF Symbol: photo.on.rectangle).
   - Camera uses `.fullScreenCover` with a `UIImagePickerController` wrapper (UIViewControllerRepresentable) for `.camera` source type.
   - Photo Library uses SwiftUI `PhotosPicker(selection: $selectedPhotoItem, matching: .images)`.
   - `.onChange(of: selectedPhotoItem)` loads the image data and calls `handlePhotoImport(image:)`.

4. **Loading overlay (D-09):**
   - When `isLoading == true`, overlay the entire sheet content with a `ZStack` containing `ColorTokens.background.opacity(0.9)`, centered `VStack` with `ProgressView()` and "Analyzing workout..." text in `.Tokens.body`, `ColorTokens.text2`.

5. **Error banner (D-08):**
   - When `errorMessage != nil`, show a `VStack` below the tab content with error text in `.Tokens.label`, `ColorTokens.zoneDanger`, and a "Retry" button.

6. **Handler methods:**

   `handleTextParse()`:
   - Set `isLoading = true`, clear `errorMessage`.
   - Call `WorkoutLLMImportService.parseWorkoutText(inputText, client: container.supabaseClient)`.
   - On success: call `mapAndPresent(response)`.
   - On error: set `errorMessage = error.localizedDescription`, set `isLoading = false`.

   `handlePDFImport(url: URL)`:
   - Set `isLoading = true`, clear `errorMessage`.
   - Call `WorkoutLLMImportService.extractTextFromPDF(url: url)` to get text.
   - Then call `WorkoutLLMImportService.parseWorkoutText(text, client: container.supabaseClient)`.
   - On success: `mapAndPresent(response)`. On error: set `errorMessage`.

   `handlePhotoImport(image: UIImage)`:
   - Set `isLoading = true`, clear `errorMessage`.
   - Call `WorkoutLLMImportService.extractTextFromImage(image)` to get OCR text.
   - Then call `WorkoutLLMImportService.parseWorkoutText(text, client: container.supabaseClient)`.
   - On success: `mapAndPresent(response)`. On error: set `errorMessage`.

   `mapAndPresent(_ response: ParsedWorkoutResponse)`:
   - Call `WorkoutLLMImportService.mapToGroupDrafts(response)` to get `(name, sportType, sessionType, groups)`.
   - Set parsed state vars. Set `isLoading = false`. Set `showEditor = true`.

7. **Editor presentation:**
   - `.sheet(isPresented: $showEditor)` presents `TemplateEditorSheet` using the new prefill init:
     ```swift
     TemplateEditorSheet(
         coachId: athlete?.id ?? UUID(),
         prefillName: parsedName,
         prefillSportType: parsedSportType,
         prefillSessionType: parsedSessionType,
         prefillGroups: parsedGroups
     )
     ```
   - On dismiss of the editor sheet, also dismiss the import sheet.

8. **CameraPickerView (UIViewControllerRepresentable):**
   - Private struct inside the file. Wraps `UIImagePickerController` with `.camera` source type.
   - Coordinator handles `didFinishPickingMediaWithInfo` to extract UIImage and call completion.
   - Handles `imagePickerControllerDidCancel` to dismiss.

**Design system compliance:**
- All text uses `Font.Tokens.*` (never `.system()` or semantic styles).
- All colors use `ColorTokens.*` (never hardcoded hex).
- All spacing multiples of 8pt.
- 0pt border radius everywhere (use `Rectangle()`, never `RoundedRectangle`).
- No shadows.
- No accent color usage (accent is only for hero readiness score).

**Import statements:** SwiftUI, SwiftData, PhotosUI, UniformTypeIdentifiers.
