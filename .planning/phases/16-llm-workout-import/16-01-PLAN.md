  <name>Task 1: Create Supabase Edge Function for workout parsing</name>
  <files>supabase/functions/parse-workout/index.ts</files>
  <action>
Create `supabase/functions/parse-workout/` directory and `index.ts` file. Per D-05, this is a Deno.serve handler that:

1. Reads `workout_text` from the JSON request body.
2. Validates input: reject if `workout_text` is missing/empty or exceeds 10,000 characters (return 400).
3. Reads `OPENAI_API_KEY` from `Deno.env.get('OPENAI_API_KEY')`. Return 500 if not set.
4. Calls OpenAI `POST https://api.openai.com/v1/chat/completions` with:
   - model: `gpt-4o-mini` (per D-04)
   - messages: system prompt + user message (the workout text)
   - response_format: `{ type: "json_schema", json_schema: { name: "parsed_workout", schema: WORKOUT_SCHEMA, strict: true } }`
5. System prompt instructs the model to:
   - Extract ONLY exercises, sets, reps, and weights explicitly stated in the text
   - Convert all weights to kilograms (if pounds detected, multiply by 0.453592)
   - Use null for any field not explicitly mentioned (never hallucinate values)
   - Infer sport_type and session_type if obvious, default to "lifting" / "strength"
   - Group exercises logically (by day/section headers, or single "Main" group if no structure)
6. WORKOUT_SCHEMA matches the structure from RESEARCH.md Code Examples section exactly:
   - workout_name (string), sport_type (enum), session_type (enum), groups array
   - Each group: group_name, exercises array
   - Each exercise: exercise_name, exercise_category (enum), muscle_group (nullable enum), sets array
   - Each set: target_reps (nullable int), target_weight_kg (nullable number), target_duration_seconds (nullable int), target_rpe (nullable number), is_warmup (boolean)
   - All objects have `additionalProperties: false` and explicit `required` arrays
7. Parse OpenAI response, extract `data.choices[0].message.content`, JSON.parse it.
8. Return the parsed JSON with `Content-Type: application/json`.
9. On OpenAI error, return 502 with `{ error: "Failed to parse workout" }`.

Use raw `fetch()` for the OpenAI call -- no npm/JSR packages (per RESEARCH.md anti-patterns). Include CORS headers for Supabase client compatibility.

The edge function is NOT auto-deployed by this plan. The user will deploy it via Supabase Dashboard or CLI. Include a comment at the top of the file with deployment instructions:
```

// Or paste into Supabase Dashboard > Edge Functions > New Function
// Required secret: supabase secrets set OPENAI_API_KEY=sk-...
```

**ParsedWorkoutResponse (Decodable):** Define nested at top of file.
```swift
struct ParsedWorkoutResponse: Decodable {
    let workout_name: String
    let sport_type: String
    let session_type: String
    let groups: [ParsedGroup]

    struct ParsedGroup: Decodable {
        let group_name: String
        let exercises: [ParsedExercise]
    }

    struct ParsedExercise: Decodable {
        let exercise_name: String
        let exercise_category: String
        let muscle_group: String?
        let sets: [ParsedSet]
    }

    struct ParsedSet: Decodable {
        let target_reps: Int?
        let target_weight_kg: Double?
        let target_duration_seconds: Int?
        let target_rpe: Double?
        let is_warmup: Bool
    }
}
```

**ImportError enum:** `LocalizedError` conforming enum with cases: `invalidPDF`, `invalidImage`, `noTextFound`, `parseFailed(String)`, `notAuthenticated`. Each case provides `errorDescription`.

**enum WorkoutLLMImportService:**

1. `@MainActor static func parseWorkoutText(_ text: String, client: SupabaseClient) async throws -> ParsedWorkoutResponse`
   - Creates snake_case `ParseRequest` Encodable struct with `workout_text` field.
   - Calls `try await client.functions.invoke("parse-workout", options: .init(body: ParseRequest(workout_text: text)))` and decodes as `ParsedWorkoutResponse`.
   - Wraps decoding errors in `ImportError.parseFailed(error.localizedDescription)`.

2. `static func extractTextFromPDF(url: URL) async throws -> String`
   - Import PDFKit. Load `PDFDocument(url: url)`, guard else throw `ImportError.invalidPDF`.
   - Try text layer first: iterate pages, collect `page.string`.
   - If text is empty/whitespace after trimming, fall back to rendering each page as UIImage and running `extractTextFromImage(_:)` on each (per RESEARCH.md Pitfall 1).
   - For PDF page rendering: use `UIGraphicsImageRenderer` with page bounds, white fill, draw page with `.mediaBox`.
   - If still no text, throw `ImportError.noTextFound`.

3. `static func extractTextFromImage(_ image: UIImage) async throws -> String`
   - Import Vision. Guard `image.cgImage` else throw `ImportError.invalidImage`.
   - Use `VNRecognizeTextRequest` (NOT the iOS 18 `RecognizeTextRequest` -- per RESEARCH.md).
   - Set `recognitionLevel = .accurate`, `usesLanguageCorrection = true`.
   - Use `withCheckedThrowingContinuation` to bridge the completion handler API.
   - Sort `VNRecognizedTextObservation` results by Y coordinate descending (top to bottom -- VN coordinate system has origin at bottom-left, so higher Y = higher on screen), then by X coordinate ascending (left to right) before joining (per RESEARCH.md Pitfall 2).
   - Join with newlines. If empty, throw `ImportError.noTextFound`.

4. `static func mapToGroupDrafts(_ response: ParsedWorkoutResponse) -> (name: String, sportType: SportType, sessionType: SessionType, groups: [GroupDraft])`
   - Maps `ParsedWorkoutResponse` to the `GroupDraft`/`ExerciseDraft`/`TargetSetDraft` structs from TemplateEditorSheet.
   - `sport_type` string -> `SportType(rawValue:) ?? .lifting`
   - `session_type` string -> `SessionType(rawValue:) ?? .strength`
   - `exercise_category` string -> `ExerciseCategory(rawValue:) ?? .compound`
   - `muscle_group` string? -> `MuscleGroup(rawValue:)` (nil if unrecognized)
   - Each exercise gets at least one `TargetSetDraft()` if sets array is empty.
   - Returns tuple with workout name, sport type, session type, and group drafts array.

Import statements: Foundation, Supabase, PDFKit, Vision, UIKit (for UIImage, UIGraphicsImageRenderer).

Do NOT add the file to the Xcode project (.pbxproj) in this task -- the executor should note this for later. Plan 02 will handle pbxproj updates for all new files together.
