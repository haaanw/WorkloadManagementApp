<objective>
Build the optional, low-friction capture UI for the niggle log: a minimal one-screen DESIGN-compliant `NiggleLogSheet` (region / type / severity / limited-training / note / Save), an on-demand Dashboard entry affordance (D-07, no nag), and a non-blocking optional post-workout nudge (D-08) that never gates the save. The sheet is its own thing — explicitly NOT folded into the daily `MorningCheckInSheet` ritual (D-09).

Purpose: give the user the highest-signal, lowest-friction way to log a localized niggle — on demand and at the post-workout moment — while honoring the no-nag ethos and the honest "load-tolerance context" framing (never "injury prediction", never diagnosis). The sheet writes through `SorenessLogRepository`, storing a `MuscleGroup.rawValue` so Phase 27 can fuse it per-muscle.

Output: `NiggleLogSheet.swift`, the Dashboard affordance + sheet hook, the post-workout nudge, and a human visual-verification checkpoint (this plan is NOT autonomous).
