Build the **suggest-and-confirm verdict card** and wire it into the Workout Log — the nocebo-safe,
autonomy-respecting surface the whole v2.0 validation hinges on. It leads with the action on the
plan + one-line reason (never a bare readiness number), offers equal-weight Accept / Keep-my-plan,

state via TEXT LABEL + optional hairline border (never color alone), en + zh-Hans.

and a deferred human-verify visual checkpoint.
