# Requirements: Tonus

**Defined:** 2026-04-20
**Core Value:** Recovery + load tracked over time — long-term insight into how the body responds to training

## v1 Requirements

### App Store Submission

- [ ] **STORE-01**: Finalize bundle identifier (reverse-domain format replacing `H.workload-management`)
- [ ] **STORE-02**: Generate App Store screenshots for 6.7" and 6.1" device sizes
- [ ] **STORE-03**: Verify GitHub Pages URLs for privacy policy, terms of service, and support are live and accessible
- [ ] **STORE-04**: Create app record in App Store Connect with metadata from AppStoreMetadata.md
- [ ] **STORE-05**: Complete age rating questionnaire and set pricing/availability
- [ ] **STORE-06**: Archive build, upload to TestFlight, submit for App Store review

### Prerequisites

- [ ] **PREREQ-01**: Fix HealthKit silent error handling in RecoveryPipeline — surface stale data indicators instead of failing silently

### Analytics Foundation

- [ ] **ANLYT-01**: Multi-week trend charts for CTL/ATL/TSB with time-range picker (4w / 12w / 6m) on Workload tab
- [ ] **ANLYT-02**: Weekly training summary with total sessions, volume, avg recovery score, load trend direction, ACWR zone distribution
- [ ] **ANLYT-03**: Week-over-week load comparison showing delta percentage for volume and session count
- [ ] **ANLYT-04**: Recovery-load correlation view — recovery score line overlaid on daily load bars (28-day)

### Data Export

- [ ] **EXPORT-01**: CSV export of workout session history (date, exercise, sets, reps, weight, RPE, volume, load) — gated behind Pro subscription
- [ ] **EXPORT-02**: CSV must exclude raw HealthKit data (only composite scores allowed per Apple guidelines)

### Intelligence

- [ ] **INTEL-01**: Training block detection — auto-detect accumulation, intensification, deload phases from volume/intensity trends over rolling 3-4 week windows
- [ ] **INTEL-02**: Periodization display on dashboard showing current detected phase with plain-language labels
- [ ] **INTEL-03**: Data sufficiency gate — show empty state when insufficient data for periodization detection (minimum 8 weeks, 3+ sessions/week)
- [ ] **INTEL-04**: Fatigue pattern detection — identify recurring recovery dips correlated with training load spikes at the individual level
- [ ] **INTEL-05**: Fatigue insights displayed as human-readable patterns (e.g., "Recovery drops 2 days after high-volume upper body sessions")
- [ ] **INTEL-06**: Behavior tagging — user can tag daily behaviors (caffeine, alcohol, travel, stress, etc.)
- [ ] **INTEL-07**: Behavior correlation — after sufficient data (5+ yes/5+ no per tag), show recovery impact percentage

### Onboarding

- [ ] **ONBRD-01**: First-run guidance after signup — direct user to first action (log workout or wellness check-in)
- [ ] **ONBRD-02**: Sport/training preference setup during onboarding flow (sport type, training frequency, experience level)

## v2 Requirements

### Coach Analytics

- **COACH-01**: Coach PDF report — branded summary for a date range with load chart, recovery chart, PR highlights
- **COACH-02**: Readiness-adjusted weekly plan suggestion based on recovery trend + load history

### Engagement

- **ENGAGE-01**: Push notifications for weekly summary delivery
- **ENGAGE-02**: Streak tracking for consistent training/check-in habits

## Out of Scope

| Feature | Reason |
|---------|--------|
| Manual mesocycle/ATP planner | TrainingPeaks owns this space; Tonus's value is automated detection |
| AI chatbot / conversational coach | LLM infrastructure cost + liability; keep autoregulation rule-based and transparent |
| Social/leaderboard features | Strava owns social fitness; focus on individual + coach-athlete depth |
| Full workout plan builder | Tonus tracks and analyzes — not a programming tool (Juggernaut AI, Dr. Muscle) |
| Real-time session analytics | Requires Apple Watch companion app (out of scope) |
| Calorie/nutrition tracking | Different product category (MyFitnessPal, MacroFactor) |
| Apple Watch companion app | Defer until core iOS experience polished |
| Android | iOS-first; revisit after market fit established |
| Raw HealthKit data export | Violates Apple HealthKit guidelines; only composite scores in exports |
