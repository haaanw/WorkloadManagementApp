# Quick Task 260605-v15: Self-Coached Strength Reset Summary

**One-liner:** Recut the visible v1.5 app and App Store copy around self-coached strength/hybrid training instead of generic workload management, coach SaaS, collaborative template sharing, and side-feature sprawl.

## What Changed

### Task 1: Lock visible v1.5 product to self-coached athlete mode

- `MainTabView` now always renders the athlete tab set: Home, Log, Recovery, Load, Profile.
- Removed the coach-mode tab branch from `AppRouter`.
- Foreground sync now uses the athlete push/pull path in the visible shell.
- Screenshot mode now forces athlete mode and no coach entitlement override.
- The old context switcher path is removed, so old coach-enabled accounts do not reveal a coach switcher.

### Task 2: Remove redundant Dashboard side quests

- Removed cycle tracking prompt from the Dashboard.
- Removed cycle status strip from the Dashboard.
- Removed the generic niggle-log action from the Dashboard.
- Preserved the v1.5 core flow: readiness hero, primary training CTA, load, metrics, weekly summary, recent sessions, welcome/setup, and HealthKit connection states.

### Task 3: Make Profile a lean self-coaching settings screen

- Removed visible cycle/hormone settings from Profile.
- Removed visible coach mode, invite, linked coach, and linked athlete sections from Profile.
- Removed ACWR method and load metric tuning from the primary settings path.
- Preserved athlete identity, training profile, language, weight unit, notifications, HealthKit permissions, sync status, and account controls.

### Task 4: Rewrite App Store metadata around the new PMF

- Renamed metadata from Tonus to Tuwa v1.5.
- New subtitle: "Adaptive Strength Training".
- Rewrote keywords, promotional text, description, and What's New around:
  - fast strength logging
  - future-session planning
  - recovery/load-informed adjustment
  - progress review
- Removed the old ACWR-first and coach-athlete positioning.

### Task 5: Trim Workout Log collaboration remnants

- Removed prescribed workout cards from the primary Workout Log.
- Removed shared-template import and template-share sheet routes.
- Removed AppRouter share-import deep-link handling from the visible shell.
- Preserved the v1.5 core flow: self-owned templates/programs, text/AI workout import, HealthKit import suggestions, template picker, active workout logging, and history.

### Task 6: Trim Recovery cycle/RED-S surfaces

- Removed visible RED-S attention banner from Recovery.
- Removed cycle fueling card from Recovery.
- Removed cycle phase context from the recovery score card.
- Preserved morning check-in, recovery score, HRV and sleep trends, wellness history, and recovery insights.

### Task 7: Make paywall single-tier Tuwa Pro

- Removed the visible coach tier selector from the paywall.
- Defaulted the upgrade sheet to the athlete/self-coached offer even when opened from old coach triggers.
- Updated visible Pro paywall copy away from ACWR-first language and toward adaptive strength training.

### Task 8: Remove invite and niggle live-entry remnants

- Removed invite-code deep-link routing from the root app router.
- Removed unused Profile invite/linking sheets and cards.
- Removed the post-workout niggle confirmation flow from `ActiveWorkoutSheet`.
- Deleted the dead `InviteConfirmationSheet.swift` and `NiggleLogSheet.swift` files and removed their Xcode project source references.
- Workout save now returns to the training loop after any PR/spike banners resolve.

### Task 9: Remove cycle permission and pipeline wiring

- Removed cycle-only HealthKit read categories from the authorization request.
- Removed `CycleTrackingService` from `AppContainer`.
- Stopped Dashboard and Recovery from passing cycle dependencies into recovery refreshes.
- Simplified `RecoveryPipeline` so the live v1.5 path uses HRV, RHR, sleep, wellness, and ordinary baselines only.
- Removed same-phase cycle baselines and shadow-cycle logging from the live recovery run.

### Task 10: Delete dead template-sharing and prescription UI files

- Deleted the old template sharing service.
- Deleted share-code, share-import, and share-preview sheets from Workout Log.
- Deleted the now-unused prescribed-workout card.
- Removed all five deleted files from the Xcode project source list.

### Task 11: Delete compiled coach/invite UI slice

- Removed `.withContextSwitcher()` from the visible athlete tabs and deleted the no-op switcher file.
- Deleted coach roster, client detail, coach workout entry, coach prescription, coach template editor/list, coach export, and duplicate prescription files.
- Deleted `InviteService` plus the invite/coach roster/coach relationship tests that only served the removed v1.5 slice.
- Kept the self-owned template list/editor by adding the top-level template files to the app target.
- Moved the date range chip into `PDFGenerationSheet` so athlete PDF export still builds after coach export deletion.

### Task 12: Remove residual old-mode and unused cycle UI code

- Deleted unused compiled cycle/RED-S UI components: `CycleStatusStrip`, `CycleFuelingCard`, and `REDSAttentionBanner`.
- Removed hidden `AppMode` state from `AppContainer` and the forced-athlete mode reset from `AppRouter`.
- Removed the unused `AppMode` enum from `Enums`.
- Collapsed the paywall code to one `SubscriptionTier.athletePro` branch.
- Changed `SubscriptionService` to fetch only the `athlete_pro` offering while still treating a legacy `coach` entitlement as Pro access.

### Task 13: Remove coach report and dormant relationship/prescription sync lanes

- Removed the coach roster PDF data type and generator from `PDFReportEngine`.
- Removed dead coach export localization keys.
- Removed uncalled coach relationship sync methods from `SyncService`.
- Removed `coachRelationships` from `SyncEntity`, so sync status no longer tracks a dead Coach Links lane.
- Removed prescribed-workout push/pull from foreground sync and deleted the prescribed-workout sync DTO.
- Removed the old prescription loading/completion path from `ActiveWorkoutSheet`; starting workouts now comes from blank entry or self-owned templates only.
- Kept the `PrescribedWorkout` model and PRS dual-run tests for a later migration-aware cleanup pass.

### Task 14: Prune obsolete strings and remaining template-sharing hook

- Replaced the remaining coach-named template empty-state string with the self-owned template hint.
- Removed the dormant template-sharing callback and context-menu action from `TemplateCarouselSection`.
